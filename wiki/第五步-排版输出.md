# 第五步　排版输出（output）

产物跑好、文本定下来以后，用这一步把结果导出成别人能用的东西：逐列文本、网站与 book-text 用的 `lines.md`／`pages.json`／`norm.json`、维基文库 wikitext、重排成段落的文本，以及与整理本对勘的 HTML 报告。

这一步只读产物，不改任何东西，随时可以跑。它原是 open-guji-cv 的 Step9，2026-11-23 起代码搬进 guji-manager（`guji_manager/output/`）。

## 常用

```bash
# 列出本步命令
guji output commands

# 逐列文本：reports/<册>/<册>.md
guji output export md vol03 -w <工作区>

# book-text／网站用的三件套（章号、meta、拆页表自动填）
guji output export format vol03 -w <工作区>
guji output export format vol03 -w <工作区> --format char-cord     # 出 char 格式

# 维基文库：先出 9.1 md 再转 wikitext；或只转一份手改过的 md
guji output export wikisource bxgb -w <工作区>
guji output export wikisource bxgb --md 某.md

# 分行 md 重排成段
guji output export reflow 某.md --out 某-段落.md

# 与整理本对勘的 HTML 报告
guji output collation-report --book vol03 --pages 4-60
```

## 要点

- 没有 seed_admit 产物的页（目录、空白页）自动跳过，会打印跳过了哪些。
- `format` 推不出章号时给 `--chapter NNN`；没有 meta 时照 cv 仓 `doc/formats/samples/guji_format_v0.1/meta_vol03.json` 改一份，用 `--meta` 指定。
- 换包后只换格号变了的页：取新 ★main 包（`guji pipeline products pack fetch`），`guji output export format <册> --format char-cord`，再走 `guji feedback swap book-text`。

规格见 [doc/5-排版输出](https://github.com/open-guji/guji-manager/blob/dev/doc/5-排版输出/README.md)。
