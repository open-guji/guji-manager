# 1c 选页试运行

> 属于 [第一步 新书启动](第一步-新书启动)。

**输入**：1b 定下的册配置、页型、套书。
**输出**：先行册试跑叠图人看过；整理本页钉位一一对应；借库首跑；首批人审字形入库并钉 `glyph_pin`；关口 A 达标。
**命令**：`guji start source pull`、`guji pipeline <管线> <册> --pages dev_set`（cv）、`guji pipeline product overlay`、`guji pipeline seg check`、`guji pipeline triage`（快审分流）、`guji pipeline review-pages build char_grid`、`guji pipeline glyph-db snapshot／pin-verify`。

## 顺序

1. 取图，`dev_set`（或 samples 10–30 页）试跑到切分各步，看叠图；整页、整列成片的问题在这里拦下（下文「取图、dev_set 试跑」）。
2. 整理本钉页位：「我们的页 ↔ 整理本半叶」一一对应、不多不少；目录页建 TOC 参照段。见 [冷启动快审流程](冷启动快审流程) 前半。
3. 借别家字形库跑一遍匹配（`workspace.yaml` 的 `glyph_lib.borrow`）。
4. 首批字形入库：按[字形快速入库：四层页](字形快速入库)（快速审阅单 → 高置信 → 低置信 → 难认字）；与整理本一致的格先过[快审分流](快审减量)减量。入库、出快照 `g<N>`、钉住，从 `glyph_match` 重跑。
5. 核关口 A：先行册无整页／整列成片切分错；人审率 ≲1%；常用字本书刻例 15–20 例／字，「库里没有」的常用字占比 <30%。

**建议一次冷启动做 2–3 册**：同一个字能收到更多不同位置的写法（史記册 01 是 1,793 + 231 个）。

## 取图、dev_set 试跑

```bash
guji start source pull <册> -w <工作区目录>       # 读令牌就够，按页表落到 raw_dir
guji pipeline keben_body_v2 <册> -w <工作区目录> --pages dev_set --to border_detect --no-pack
```

`--no-pack`：试跑不存产物包。看 `products/<册>/border_detect_gate/p*.json` 的 `admitted／reject／flags`，再把 `border_detect/p*.json` 的版框、界行画到原图上逐页看。

**这部书的试跑结论**（叶 10、叶 30 各两个半叶）：
- 版框上下边基本找得到；
- **没有界行**（坊刻，列靠字距分开），Step1 只能拿文字缝凑竖线，竖线穿字，p18 探出 8 列被闸拦；
- **鰲頭两栏**：多数叶上栏是插图配大字或另起一段，下栏是正文，竖线从上栏一路穿到下栏；
- 大字正文夹双行小注、字号不一，`expected_cols／chars_per_line` 这种整册常量对它不成立。
现有 `keben_body_v2` 跑不了这部书。要跑得先在 cv 补：无界行的分列（按字缝，类似现代链 `line_detect`）、上下栏分开（Step0 `page_split` 只有影印本那种「两栏是两页」的 `two_rows_hline`，鰲頭的两栏是两路文字，读序要另定）、大小字混排。这是 CV 需求，不是配置能调好的。


## 字形库冷启动（简要）

> **字形快速入库一律按 [字形快速入库：四层页](字形快速入库) 做**（Sheldon 2026-11-10 定）：快速审阅单 → 高置信度 → 低置信度 → 难认字，每层的选字与验收标准都在那里。

1. 逐列整理本进中心库（`guji start corpus init`，册 yaml `references:`）；
2. 页钉位（`scripts/make_page_pins.py`）：先确定「我们的页 ↔ 整理本半叶」的规则并核到「一一对应、不多不少」；
3. 借别家字形库（`workspace.yaml` 的 `glyph_lib.borrow`）跑 Step5a 匹配；
4. 字形入库：按 [字形快速入库](字形快速入库) 的四层页做（出页、取数、落库、重跑 `--from glyph_match --force`、验收都在那里，这里不重复）；
   机器已放行、库里却缺例的字不用人看，由[放行格回库](放行格回库)自动补（`glyph_lib.auto_backfill`，整册跑完触发）。
   回库之后同一个钩子还会把库里每个刻例的字和这一册文本逐格核对，见[库文一致](库文一致)（`glyph_lib.text_check`）。
5. 推中心库（先报条数，等用户点头）。
