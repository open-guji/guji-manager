# 第一步：常见坑

- 云会话删不了远端分支（`git push --delete` 断连、GitHub API 403）。用中转站：`CLAUDE_RELAY_FROM=<你> python3 process/branch_delete.py <owner/repo> <分支>`（令牌是环境变量 `CLAUDE_RELAY_TOKEN`；main、rc/*、有开着 PR 的分支会被拒）。删前仍要用户点头。
- `gh` 的 GraphQL 被代理拦：建 PR、转 ready、合并都用 `gh api` REST。
- 会话里 `/opt/guji-venv` 装的是 `/opt/guji-cv-seed`（发布版），要用本地改过的 cv：`PYTHONPATH=<cv 克隆> /opt/guji-venv/bin/python -m open_guji_cv …`。
- book-index 仓大，`git pull` 可能几分钟不返回，放后台。
- 面板里写的 `GUJI_DATA_TOKEN=$GUJI_DATA_TOKEN_PROD` 不会展开，命令前自己展开。

更多见各案例页。
- **新书仓没有模板**：以前照上一本书手抄。现在 `guji start new <书id> --title …` 一次出齐初始文件（MBJ、WYG 11-27 开书经验）。`.gitignore` 要含 `_packs/ reports/ perf/`，旧书抄全唐文会漏。
- **云会话取 Commons 原件 429**（`upload.wikimedia.org` 必 429，缩略图只认标准宽度）：首选在书仓加一次性 GitHub Actions workflow 下载、sha1 对 Commons imageinfo 后作 artifact（保留 2 天）传回，WYG 汉书走通（`commons-fetch.yml`）；次选请用户浏览器下载后 stage（MBJ，几 MB 的 DjVu 一分钟）。Commons API 要 urlencode，间隔 ≥8 秒。
- **云会话建仓 403**（组织级接口被沙箱拦）：用 ai-team `process/repo_create.py`（relay `POST /repo`），不用令牌直连。
- **`guji db init` 要先有 `books/<册>.yaml`**，`guji source pull` 也要先有最小册 yaml（id／title／raw_dir／raw_pattern）且 `-w` 显式给；所以语料与 `config/book_defaults.yaml` 要等 1b 写完册 yaml 才一起进库。
- **新书 db init 后字形库真源没有 `meta.jsonl`**：整册跑完自动回库报「字形库没有 meta.book_edition」。不要 `glyph-db set-edition --apply`（会把借来字头的 edition 一起改成本书）；在 `<数据目录>/output/glyph_store/meta.jsonl` 写一行 `{"key": "book_edition", "value": "<书id>"}`，再 `guji glyph-db rebuild -w . --store <该目录>`。db init 之后立刻做。
- **`db push` 缺省不推字形库账本**：回库、人裁入库后要 `--with-glyph`，先 `--dry-run` 看 glyph_* 表只有 insert、条数等于真源 exemplars.jsonl 行数。
- **`db pull --force` 会用中心库的 workspace.yaml 盖掉本地改动**：改了 workspace.yaml 先 `guji db push` 再 pull。
- **按页行款**：序文大字页等与正文不同的页，`expected_cols_pages` 要在 `border_detect`、`column_geometry` 等各处都写（MBJ 要写五处）；每列字数用 `chars_per_line_pages`（cv v0.9.8 起，之前没有参数，体检没核出来、劈字错误上了网站）。体检必须按页核列数与每列字数、抽页叠图看。
- **四周單边的书边列被切窄**：`border_detect` 自由模式可能把穿过边列字的竖线当内框；体检时按页量边列宽（< 中位数 80%）；列距整齐的书用网格模式 `column_grid_pages` + `grid_col_pitch`。
- **拆页登记 pagemeta 报「拆页源图宽高没给」**：要自造 src-sizes json（键 `s1:<文件>_<页>.tif`），WYG 汉书遇到；`source commons` 只登一整册，一书多册（文渊阁）要自定册划分（按书名签切册，末册 end 排除封底，附书起点截断）。
- **新书首次进 book-text**：要先手建条目（`Book/<id 末三位逐位>/<id>/manifest.json`、`default/index.json`），出 v0.1 脚本加章后跑 `u_migrate.py apply`、`uid init`，删 cord cells[].id，`local_check` 才过。首发前设 `GUJI_AUTO_ONLINE_LISTS=0`（存包 `--main` 会后台自动重出线上单）。
- **出 v0.1 用 `--force` 前**先列闸拒因，逐条说明；**重切后重发单**要先 `uid init`／`uid advance`。
- **参校本是 OCR 稿**：`lib_missing／own_zero_borrow_has`（参校本字本书库没有）不要拿参校本字当预选做快审，第一页就大多是 OCR 错；这类格先用机器读或库前几名排预选，或直接放网站。`align` 层主要是参校本 OCR 错和异体，该出 `ref_check` 复核页，不是交切分线。
