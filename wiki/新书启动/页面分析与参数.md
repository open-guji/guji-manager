# 1b 页面分析与参数

> 属于 [第一步 新书启动](第一步-新书启动)。

**输入**：1a 准备好的原图、整理本、册在中心库。
**输出**：本书「版式档案」（是否等距、落缝范围、夹注、题署列、列端框线）；页型声明；套书 `seg_set`；册配置与书级开关；开书体检单与目标人审率。
**命令**：`guji start pagekinds`（页型对账）、`guji pipeline binarize`（墨层与二值体检）、`guji start suggest`（诊断信号→开关建议）、`guji pipeline pending-stats`（诊断信号表）、`guji pipeline glyph-db selfcheck`。

## 做什么

1. **量版式**：试跑看图（见 [1c](选页试运行)），判断版式和已有书是否一样（下文）；写进工作区 README 的版式档案。
2. **页型普查**：正文、目录、职名（roster）、表格（table）、书衣（cover）各占多少；在册配置里声明，跑 `guji start pagekinds` 对账。
3. **选套书**：按版式选 `seg_set`；新版式家族的第一本书另算工期，切分不适配的交 A22（是 CV 需求，不是配置能调好的）。
4. **墨层与二值**：默认都二值化（用户 11-17 定），书配置写 `ink: {}`。
5. **册配置与书级开关**：最少字段见下文；书级开关按 [书级开关与跑批分支](书级开关与跑批分支) 的原则写（缺省关、证明等价、有语义的参数）。只给一本书用的新行为放书仓 `code/`，不往 cv 共用 Step 加开关。
6. **借库**：本书库为主；借别的书只借人裁刻例、钉快照号，只作备选不当证人，见 [借库写法](借库写法)。
7. **体检单**：参校本错率、页型占比、套书、借库、码位策略、预计起步率、建议目标人审率（参考 0.3% 稳定／0.2% 目标／0.1% 挑战）。用户定目标，写进后台。细节见 [开书体检](开书体检)。

首跑出数后，开关不靠人读表配，按 [终审判读与开关建议](终审判读与开关建议) 用 `guji start suggest` 出建议、点头后写册 yaml。

## 册配置怎么写

`books/<册>.yaml` 最少：`id`、`title`、`edition: keben`、`raw_dir: data_full/<册>`、`raw_pattern: "{page}.png"`、`expected_cols`、`chars_per_line`、`dev_set`。其余（`leaf_layout`、`period_prior`、`bottom_gap`、`top_band_frac`、`column_grid`、`font`…）都是**本书实测**才能写的先验，字段说明在 cv `open_guji_cv/core/book.py` 的 `BookSpec` 注释里，北行日錄的 `bxgb.yaml` 是写得最全的样板。**别抄殿本的数**，换书一律重量。
多册的书才用基础配置 `config/book_defaults.yaml`（殿本）；单册书不用。


## 版式和已有书一样怎么办
《史記》文淵閣本与《欽定四庫全書總目》武英殿刻本版式基本一样（满页 8 列、每列约 21 字、双行小注），所以直接沿用 `config/book_defaults.yaml` 里的殿本配置就能跑，**不用重新定义切分**，只改册 yaml 里的 `id／title／raw_dir`。判断办法：试跑 dev_set 的 Step1–4，看叠图列线是否落在字缝、版框是否包住全文。
**版式不一样**（无界行、双栏、字号不一，如《幼學須知》鰲頭本）：`keben_body_v2` 跑不了，要先在 cv 补切分（这是 CV 需求，不是配置能调的），本阶段到「叠图人看过、写明哪里不行」为止。
