# 2b 切分检查与优化

> 属于 [第二步 自动化流程](第二步-自动化流程)。

格框对、格号对、配上整理本。切分一动，格号、刻例、人裁锚都要迁，所以每轮最先清。

**输入**：本轮 `guji pipeline seg check`／`seg gate` 给出的结构列清单；下游各层报回来的切分错。
**输出**：修好的切分（cv PR、书仓 `code/` 新 `k`、册配置、`manual-cells` 钉子）；根因台账与本书尺子更新；`切分未定.tsv`。
**命令**：`guji pipeline seg check／gate／premain／pin／pins-stale／ruler`、`tools/seg_check/seg_check.py`、cv `scripts/seg_pins_check.py`、`guji start code release／verify`。

做法以 [迭代流程 第 1 层](迭代流程#第-1-层切分含对位页钉位) 为准：先查根因台账 → 修法由便宜到贵（公用算法 → 书级代码 → 本书配置 → 单页单列钉子）→ 漏检即进尺子。看图判切分由会话做，不交用户。

## 整列钉子（manual-cells）的两条例行

- **标 main 前跑** `guji pipeline seg pins-stale [册…]`，退出 3 就先处理、不标 main：
  - `stale`：钉子当时的列图几何（`geom`）和现在的不一样。cv v0.9.6 起重跑 row_segment 会自动把钉子换算到新列图，位移超过 3px 的列打 `manual_cells_remapped`、送人核；老钉子没记 geom 的要 `seg pin` 重核。
  - `unapplied`：新钉或改过的钉子还没用进本页 row_segment 产物，从 row_segment 起重跑这些页。只比内容（产物列有没有 `manual_cells` 旗、格号与坐标对不对得上钉子、manifest 里记的本册钉子指纹），不比时间戳。
- **升级到 manager ≥ v0.6.35 后跑一次** `guji pipeline seg pins-backfill-geom [册…] --write`，给老钉子补几何底；只补现行列窗与当时一致的，补了产物不变。补不上的会列出来，先 `seg pin` 重核。

细节见 [钉子上游底](../doc/参考/钉子上游底.md)。
