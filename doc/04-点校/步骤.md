# 点校：步骤

> 仓：book-text（文本与伴生层）、book-index（实体）、guji-format（格式规范，不归专人）。令牌见 [环境与令牌](../00-总览/环境与令牌.md)，本文不写凭据。

## 总流程
```
取册文本 → 预标（标点＋专名）→ 复看／交叉检查 → 专名匹配 → 入库（--init 0.1.0）
        → 库无实体转实体库 → 回挂 → 随改字局部重标 → 抽样验收（升 1.0 前）
```

## 1. 标注来源（按册选）
- **第 1～20 册**：逐句标注稿（`m{册}_NN.txt`）经 conv/build/qc 转出 punct/entity，疑难处人工裁定（`ov{册}`）。
- **第 21 册起（不训练模型）**：用外部模型直标原文，再与外部已标点包、维基文庫同书文本做停顿交叉检查，出复看清单。
  - 按自然段切小段（约 450 字／段），一次调用要短：大段容易空输出、超时被杀。空输出就拆半重跑。
  - 外部模型由常驻会话经文件队列调用（in/out/status），额度用尽自动换轻量档；轻量档与外部包一致率不低于最强档，但少标书名，书名需靠匹配补。
  - 校验脚本必须核「汉字未改」。
- 页序乱的册：按读序表拼正文，`char_offset` 仍按格序，跨倒序页的专名不出实体（标点保留）。

## 2. 专名匹配
- 书名：NFKC → 自备异体表 → opencc t2s → 再过异体表后比对。
- 史志篇名直接挂上位书并带 `coarse: part_of_work`；经传篇名（說卦、文言…）挂《周易》，同样带该标记，将来细化。
- 省称配书三道闸：撰人在上下文（±150 字）；书名前缀一致且占全名一半以上；排除泛称（周易、易傳、目錄、正義、文集等）。同名书靠上下文撰人定，定不了记 `ambiguous`＋候选。
- 人名：拆合称（老莊、二程）、按上下文补全省称，查维基／CBDB，统一一个标准繁体；朝代补全；合称年号用 `matched_multi`；并列条目用多链接，上下级拆分用 decomposition。
- 官名：参考维基酌情；同名异朝的官按原文朝代选条；兼任两官用 `matched_multi`，各 part 拼起来须等于 span 文本。
- 地名：暂不建，留 `new_candidate`。拿不准的标待确认，不硬挂。

## 3. 入库
1. 新册首次入库走 PR（分支→草稿 PR→自审→squash 合并）；`bump_original.py --init --line punct|entity`（初始 0.1.0）。
2. 重建 `index/texts` 后跑 `local_check.py`（含 strict、collated）。稀疏克隆时「index/texts 一致」项会因重建截断假失败，不提交索引。
3. 4～5 册合一个 PR。CHANGES.md 只替换自己那几行的 `#TBD`。

## 4. 库无专名
本步产出「库无」清单（人、书、官分类）→ 交实体库负责项目建档 → 按其建档结果表回挂（`new_candidate` 改 `matched`，省称并入时同步 `end_offset`、anchor.end、删被吞 span）。书名归书目项目，出版者归出版者项目。

## 5. 改字后的局部重标
- 单字替换：`scripts/book-text/punct_redo.py` 的 plan/apply，只修锚点与校验字，两线升 patch，`local_check --dev` 后推 dev，再通知点校项目复核断句与专名换挂。
- 增删字／整句改／plan 投不上：推分支，点校项目在分支上重标后合 dev。
- 在 dev 上：merge main → plan → apply（`--old-char git:origin/main`）→ bump patch → 重算 headings → `git checkout origin/dev -- index/texts` → `local_check --dev` → push dev。

## 6. 版本规矩
标点线、专名线的改动（复核、改链、重链、回填 id、单字锚点修复）**大多只升 patch**；仅整册重跑、新增类型、新分段规则升 minor。第一次入库照旧 `--init 0.1.0`。`bump_original.py` 需带 `--pr 号`：先开草稿 PR 拿号，再 bump、重建索引、跑检查。

## 7. 回写
改点号后同步 `stats.points / total_annotations / commas / periods`（手写字段，local_check 不核）。
