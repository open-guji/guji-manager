# 点校：常见坑

## 标点
- 模型典型错：逗号错位一格（落在「撰」前，应在撰后）；引文闭合位置不对（把提要作者的话包进 `」`）；列举句少断；句末缺 `。／？`。
- 《》内不能加「·」；篇名写《吕覽》審微篇式。正文并入的下一条标题要单独成段。
- 分段点：类目行里的异体字（如「𩔖」）要识别，否则 `##` 缺失报 F-OV-12。
- 标题头被排到上一段正文末尾的，入库脚本需修。
- 页序乱的册别硬标：先要读序表。

## 专名
- 「唐、虞」并称的唐是陶唐氏不是唐朝；《春秋》某公某年传的公按鲁公补全。
- 儀禮／禮記／周禮篇名与吳澄《儀禮逸經》篇名要分清挂哪本。
- 单字省称书名（集傳、纂言、綱目、經傳通解）自动匹配常错，逐条看撰人；opencc 不折 攷／葢／𢑴／𫎇，异体表须自己补，只用 t2s 漏配约三成。
- 卦名／爻位误标书名：删实体连同《》，并同步 punct stats。
- 「太祖」「馬」「稷」这类单字、帝号要人裁；按朝代分的官名自动挂法不可用。
- 先归一再比，再说库无；别的会话留在 dev 的 `#TBD` 不要全局替换。

## 流程
- 多个会话同改一册 entity.json 极易冲突：冲突时从 origin/main 新分支重做脚本，推送后立即合并。
- 维基文庫 API 对共享出口限流（429），慢速重试；其总目标点很粗，只当停顿信号。
- 凡「先粗略挂、以后细化」的链接，在 target 里留可检索的 flag，别只写 note。
- 脚本 `json.dumps(indent=2, ensure_ascii=False)+'\n'` 可原样往返实体 json。
