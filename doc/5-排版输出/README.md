# 第五步　排版输出（output）

按 book-text 导出排版文本。cv 原 Step9 移来（2026-11-22 用户定），代码暂在 cv，命令已归 `guji output`。
怎么做见 Wiki [第五步-排版输出](../../wiki/第五步-排版输出.md)。

| 命令 | 输入 | 输出 |
|---|---|---|
| `guji output export md <册>` | 产物或 book-text | 逐列文本 |
| `guji output export format <册>` | 只读产物 | lines.md、pages.json、norm.json（格式见 cv `doc/formats/`） |
