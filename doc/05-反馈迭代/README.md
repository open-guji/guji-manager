# 05 反馈迭代

## 目标
专指版本达到 1.0 之后：(1) 网站上用户的报错和反馈如何收集、判定、修订并发新版；(2) 算法提高后，机器给出的反馈（新旧结果差异、疑点）如何处理；(3) 保住人裁与手改，改动可追溯、可撤销。与第 2–4 步相互独立，排在它们后面。

一句话：**已发 1.x 的文件不手改；一切改动先是意见、再有裁决事件、最后只经 `revise` 落地，一批一个 PR。**
