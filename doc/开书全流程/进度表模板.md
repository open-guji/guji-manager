# 进度表模板

每本书的工作区仓根放一份 `开书进度.yaml`，是这本书开书流程的**唯一当前状态**。会话换了、容器回收了，读它就能续上。改动随进度提交（commit message 写步骤号）。

```yaml
book_id: 995ejelvk0
title: 全唐文
ws_repo: guji-workspace/995ejelvk0-quan-tang-wen
goal: v0.1            # 粗校 0.1.0 + 标点 0.1.0 + 专名 0.1.0
pilot_vols: ["04"]    # 先行册；关口 A 达标前只做这些
all_vols: []          # 全册清单，S2 后填
reference:            # S3 的账
  source: Kanripo KR4h0168
  line_is_column: true
  notes: "参校本自己分行与刻本不同的地方多，列字数一致率 ~95% 是上限"
glyph_borrow: []      # S8 借的库
approvals:            # 用户批准的范围，别写含糊
  - what: "04 册产物推中心库"
    by: Sheldon
    on: 2026-10-31
    scope: once       # once | standing
steps:
  S5: { status: done, note: "period_prior 205" }
  S6: { status: in_progress, note: "目录页 96.7%，余第 3 页手工补" }
  S7: { status: done }
  S8: { status: in_progress }
gates:
  A: { status: pending }
  B: { status: pending }
review_queue:
  - id: 995ejelvk0-S8-1
    kind: review
    step: S8
    blocking: [S9]
    size: "30 页 × 30 格"
    est_minutes: 40
    link: "<审阅页 Artifact 链接>"
    created_at: 2026-10-31T04:00:00Z
    last_nudged_at: null
    nudge_count: 0
    status: open
next_wakeup: 2026-10-31T10:00:00Z   # 约下次醒来
```

字段约定：`steps.<S>.status` ∈ `todo | in_progress | blocked | done`；`blocked` 必须写 `blocked_by`（队列项 id 或外部原因）。队列项字段见 [人不用催机制 §二](人不用催机制.md)。
