# 01 开新书：验收标准

做完三阶段的标志（逐条核）：

| 阶段 | 标志 | 怎么核 |
|---|---|---|
| 一 资源准备 | book-index 有 Work／Book，Book 只挂一个最新原图资源 | `check_schema.py`、`check_v2.py` 过；PR 已合 |
| 一 资源准备 | 原图在 R2，页表页数对、对开拆页核对图逐张看过 | `guji source commons ... --dry-run` 页数；核对图红标落在折痕上 |
| 一 资源准备 | 有逐列整理本，或明确记下「没有」 | 语料进中心库 `corpus/`；没有则冷启动那套用不了 |
| 二 工作区与试跑 | 册在中心库 | `guji db status` 显示 behind 0、unpushed [] |
| 二 工作区与试跑 | dev_set 试跑 Step1–4 叠图人看过；版式一样沿用已有册配置，不一样写明哪里不行 | `products/<册>/border_detect_gate/p*.json` 与叠图 |
| 三 冷启动 | 快审入库，`--from glyph_match --force` 重跑后字形库有人审字形 | 条数报给用户，推中心库前等用户点头 |

建议一次冷启动做 2–3 册而不是 1 册（同一个字能收到更多位置的写法）。
