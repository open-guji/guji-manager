# 01 开新书：常见坑

- 云会话删不了远端分支（`git push --delete` 断连、GitHub API 403）。用中转站：`CLAUDE_RELAY_FROM=<你> python3 process/branch_delete.py <owner/repo> <分支>`（令牌是环境变量 `CLAUDE_RELAY_TOKEN`；main、rc/*、有开着 PR 的分支会被拒）。删前仍要用户点头。
- `gh` 的 GraphQL 被代理拦：建 PR、转 ready、合并都用 `gh api` REST。
- 会话里 `/opt/guji-venv` 装的是 `/opt/guji-cv-seed`（发布版），要用本地改过的 cv：`PYTHONPATH=<cv 克隆> /opt/guji-venv/bin/python -m open_guji_cv …`。
- book-index 仓大，`git pull` 可能几分钟不返回，放后台。
- 面板里写的 `GUJI_DATA_TOKEN=$GUJI_DATA_TOKEN_PROD` 不会展开，命令前自己展开。

更多见各案例页。
