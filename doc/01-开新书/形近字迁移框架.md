# 形近字方案迁到一部新书：框架（待填）

> 2026-10-29 A31 起框架，内容慢慢往里填。第一个实例是《史記》文淵閣本（`988g3f0wsu`）；A24 的原计划见 `全书整理/史记/迁移计划-2026-10-28.md`，用户逐项决定见 `全书整理/史记/迁移决策-文渊阁史记.md`。
> **前提：阶段三（字形库冷启动）做完之后才开始。** 没有这本书自己的人审字形和整理本对位，形近字的金标就没有。
> **原则：逐项区别讨论，不一刀切。** 每一项落进下面三个状态之一，并写依据。

## 状态
- **直接用**：理由站得住（例：语料同为清代，文意头可直接用）；仍要在本书上按册留出，错放 0。
- **先测**：方法可迁，数据或门槛要在本书验证（对应 A24 的 T1–T9）。
- **不用／本书重建**：数据与本书不匹配（例：字频表），或默认关（例：暂归一）。

## 步骤（每走一步在上表填「结果」）
1. 确认前提：本书整理本、样本册（建议每个体裁一册；史记＝本纪、表、书、世家、列传各一册）、字形库口径、册 yaml 的 `period_prior` 与 corpus 钉。
2. 样本册跑到 `seed_admit`，`guji groups status --prod <产物根> --out <目录>` 出表（T1）。
3. 按送审数从小到大逐组开线程，每线程一两组，在自己训练集上训，通过再合语料库。
4. 样本册通过 T1–T7 之前**不出线上待审单、不标 main**。
5. 通过后给出「册 yaml 字组配置 + 书层语料版本」，其余册跑到 seed_admit 时直接套用。

## 已经知道的本书特点（史记文渊阁，持续补）
- 手写馆阁体，笔画比刻本粗而清晰，同乾隆朝，写法很多与殿本类似。
- 册 01 里有一批整理本没有对应字的格（职名页、表页、诗页、考证小注页），这些格不进形近字金标。
- 整理本是殆知阁光盘版，规范化程度要看具体字（写本俗字被统一成正字时，会出现「整理本字 ≠ 写本字」的假不一致）。
