# 第三步　文意与知识（text）

v0.1 之后，AI 读整段文意，一遍判三件事：靠文意才能定的形近字（日曰、己已巳、千干…）、标点、专名。判出的字写裁定库、重放进 book-text；标点、专名写 book-text 的 punct、entity 两线。剩下判不了的留给[第四步 反馈迭代](../4-反馈迭代/)网站人审。
怎么做见 Wiki [第三步-文意与知识](../../wiki/第三步-文意与知识.md)。命令前缀 `guji text`。

**教程主文：[v0.1 后点校流程：形近字＋标点＋专名合并判定](../../wiki/文意与知识/文意判字标点专名合并判定.md)**（11-20 现行；文中「第四步」「第 4 层」即本步）。

```
取问、出段 ─▶ 两路独立会话判（对话会话，管线不调 API）─▶ 机器校验（必做）
                                                         │
             ┌───────────────────────────────────────────┼──────────────────────┐
             ▼                                           ▼                      ▼
     放行判字：写裁定库、重放               标点、专名写 book-text          判不了的留人审（第四步）
                                           专名对库（第二阶段）
```

| 部分 | 做什么 | 文档 | 命令 |
|---|---|---|---|
| 文意判字 | 按待审原因的默认去向判字；文意判当人裁质检；提示词与窗口版本 | [合并判定](../../wiki/文意与知识/文意判字标点专名合并判定.md) 第四、八节 | `guji text final-review build／batches／status／finalize／write`、`guji text rulings-hits`、`guji pipeline review-pages ctx2-export／ctx2-import` |
| 标点 | 每个点号记 `(anchor, mark, pos)`，书名号、引号成对 | [步骤](../../wiki/文意与知识/标点与专名-步骤.md)、[验收标准](验收标准.md) | book-text `local_check.py` |
| 专名 | 人名、书名、官名、地名、朝代年号等，匹配中心库实体 | [步骤](../../wiki/文意与知识/标点与专名-步骤.md) | book-index 实体库 |
| 判字与标点的先后 | 同遍（默认），或判字先行再标（史記、全唐文 11-20 起试行） | [合并判定](../../wiki/文意与知识/文意判字标点专名合并判定.md) 第九节 | — |

## 入口条件

- 本批已出 v0.1（第二步自动化流程 2b–2d 判停、标 main），册配置冻结。
- 页序正确。页序乱的册先出读序表，按读序拼正文，缺页接缝处硬断句。
- 字符线之后若有改字：单字替换只修锚点；增删字、整句改须重标，见 [步骤](../../wiki/文意与知识/标点与专名-步骤.md)。

为什么排在网站人审之前：AI 读文意能顺带判掉大量形近字，人只审剩下的；待审单上带着标点专名句子（`sent`）和点校倾向字与查证备注（`dian`），见 [点校先于精校](../../wiki/文意与知识/点校先于精校.md)。

## 不做什么

- 标点、专名层不改字；改字只经文意判字写裁定库。
- 不建大批量实体：小批量可直接在 book-index 建，大批量交实体库项目；地名暂不建，留 `new_candidate`。
- 不改 guji-format 规范（谁需要谁直接改，改格式前先通知网站与搜索侧项目）。

## 产出

裁定库新裁定（重放后进 book-text 文本线）；book-text 每册 punct、entity 两线（初始 0.1.0）；库无清单交实体库；本批经验写进 [各册经验汇总](../../wiki/文意与知识/文意与知识-各册经验.md)。

## 常踩

- **裁定推了却不命中**：裁定键按出包后的窗口算，重放时邻格放行状态变了、窗口就不同。每批写完裁定跑 `guji text rulings-hits` 查「仍在问、却有裁定没命中」的格，`--rekey` 按产物窗口补写。
- 文意判当人裁质检用时，金标不进提示词；两路独立会话的结果先过机器校验再写库，见主文第四节第 3 条。
