# 4b 收单落票

> 第四步「网站人审与版本迭代」的小步。总览见 [第四步 README](../README.md)。

用户或读者在网站投完票后，落票成人裁、定字直接落 book-text、KV 结案、推库、发站核对。

## 实测与要点

- 只落票、不改文本、不重放：一册约 10–20 分，真计算不到 5 分；落票＋改 book-text＋重放＋出新单：2–5 小时，大头是等重放排队和切分返工。
- `guji collect` 一条命令收一张单：读票→写人裁→定字直接落 book-text（不重放）→KV 结案→pull、sync 各一次→发站核对，断点续跑。
- AI 裁定和人裁一样直接写进 book-text，不等下一轮重放（用户 11-20 定）。
- 各书数字：ai-team [收单各书汇总](https://github.com/open-guji-core/ai-team/blob/main/domain/CV/粗校/收单各书汇总-2026-11-18.md)。
