## 做什么
一册人审收尾后，把 book-text 底本和两个参校本逐字对比，查漏补缺，并留下「每处差异怎么处理的」记录，册清零才算完。

- 殆知阁本：book-text `96mid1ogzk/wyg-cd`（无标点，文渊阁系，己已巳不分，日曰分）。
- 维基文库：`Work/a/f/4/d59dh3vo9af4/wikisource`（浙本，带标点，己已巳、日曰都分，但繁简转写错、排版改动多）。
- 标点另走 `domain/文本/参校审阅/标点/`，这里只管字。

## 流程
1. **三方对照**：`tools/run.mjs`（book-text-util compareWhole／runCompare）→ `fixmove.mjs`（维基条目次序不同的大段错位重对）→ `tri.py`（底本／殆知阁／维基归成 A 两本同异、B 仅殆知阁异、C 仅维基异、D 三家各异、H 底本缺字）。
2. **排除不用看的**（`tools/classify.py`，判法同 book-text-util collate 表，见下节）：异体、繁简转写、维基凡例序号（一→十七）、版心书名、职名「臣」挪位、「無法顯示」占位、大段版本异文、本项目已定规矩（rules.py）。
3. **只送底本≠殆知阁的**（用户 11-14 定）：维基错得多，只有维基不同、殆知阁同底本的记「维基独异」放过，不逐条审。殿本第1–5册 911 处差异 → 送审 62 处。
4. **出审阅页让用户点**（不发拼图，见下节）。AI 不给建议：第2轮我按图建议的 鴻→鳩、目→自 都被用户否了（图上就是鴻、目），8:9:12 我以为是人名「裘曰修」，用户判「裘日修」。
5. **读回、落地**：
   - ArtifactData `list decisions` 读回；
   - 改 book-text：单格换字照 `对校后手动快速修复流程`（char.json 只改那一行；标点 `pre_char`、实体 `text` 跟改），`bump_original.py <default 目录> --line text|punct|entity --level patch --chapter NNN`，「版本记录」行进提交信息，`local_check.py --dev`，PR 投 dev 自合；
   - 写人裁：`guji cellvotes write volNN <目录> --batch H-ZM-collation-… --reviewer ZM`（目录里 drafts.jsonl＋meta.json，products_root 先 `guji products pack fetch volNN --to …` 拉现行包），`guji db sync --no-glyph` 推中心库（`GUJI_DATA_TOKEN=$GUJI_DATA_TOKEN_PROD`），再用 `latest_human` 核一遍；
   - 记录 TSV 改状态，`tools/update.py` 看未结数。
6. 册清零（未结＝转格修复／待用户判／待处理 都为 0）后在 Jira 册卡记一行。

## 异体怎么排（用户 11-14 说「过滤得比较好」）
只认可靠来源，宽松来源只在僻字上用：
- trusted 表（Unihan、yitizi、twedu、dypytz、hydzd、cjkvi-simplified 的 variant／simp／z 边，去掉 distinct 与 borrow）；
- 再加 Unihan 语义／Z 异体或教育部异体字典认定的，压过通假边（辨/辯、奕/弈、筭/算）；
- 两字有一个是扩展区字（扩展 A 或 BMP 以外）时，任何来源的 variant 边都算（𠉀/候、𭧂/暴、𨒪/速）；
- 繁简：OpenCC 转简后同形算（範/范、乾/幹、閒/閑），对维基尤其要排；
- 常用字之间只靠宽松来源（zi:link、charcomp）的**不算**异体：令/命、壁/璧、宇/字、各/名 都要人看。
- 生成表：`npx book-text-util variants --edges open-guji-cv/config/hanzi/core/edges.tsv --mode collate --out glyph-variants.json`。网站对校模式照用（A41）。

## 审阅页（Artifact）
- 第2轮（少量条目，带建议、口径卡）：`tools/sheet.py <待判.json> <out.html>`，模板 `sheet.tpl.html`。
- 第3轮起（量大）：`tools/sheet_groups.py <rows.json> <outdir>`，模板 `sheet_groups.tpl.html`；按册分数据文件 `data/vol<册>.json`（每册几百 KB 到几 MB，单文件不能过 16 MB），按组分节，每组「本组未判的全部照底本」（点两下生效）。
- 每卡：本列图（红框标本格）、本格放大、上下文（本字标红）、底本／殆知阁／维基三家读法、点字按钮、「其他」输入、备注。僻字字体显示不出时注码位（U+2E7CF）。
- 用 Artifact 发布，声明 `db` 能力；结果在 db 集合 `decisions`，文档名＝条目 id（第3轮起 `r3-<册>-<起格>[~<止格>]`），字段 pick、note、base、at。
- 殿本第1–5册用的页：https://claude.ai/artifact/5sr1U6xw7DX8uaG822NCva （同一链接换批次重发）。
- 规矩：非标准流程的审阅用 artifact，不放 openguji 网站（用户 11-09）；标准校对单才上正式站。

## 口径（用户定）

## 坑
- 记录 TSV 是 CRLF：Python 改要 `newline=''` 读写，不然整文件变一遍。
- 同一格可能有新旧两行记录（底本改过后重跑），按 (册, 起格, 止格) 对时注意旧行。
- 裁本列图时纵向要夹在页面范围内，否则底下一截黑。
- 书影走网站 IIIF（`https://data.openguji.com/iiif/96mid1ogzk/<两位册>/wyg/<4位页>/full/max/0/default.webp`），格框用 book-text `<册>.cord.json`；脚本在有 `img/` 缓存的目录下跑。
- `guji db sync` 第一次可能抛异常而实际已推，用 `--dry-run` 看待推清单里是否还有本批、再用 `latest_human` 核。
