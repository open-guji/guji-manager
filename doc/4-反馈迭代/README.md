# 第四步　反馈迭代（feedback）

机器和 AI 都判不了的格放到网站上，由读者对照原图认字；票落成人裁，更新 book-text，文本一版一版升，直到 1.0 冻结；1.0 之后继续收网站报错和机器反馈，发 1.x。
怎么做见 Wiki [第四步-反馈迭代](../../wiki/第四步-反馈迭代.md)。命令前缀 `guji feedback`。

```
4a 出单上线 ──▶ 读者在网站投票 ──▶ 4b 收单落票 ──▶ 4c 更新 book-text ──▶ 0.x 升版
     ▲                                                                    │
     └──────────── 换单（新一轮主包、新裁定）◀──────────────────────────────┘
                                                                          │ 达到 1.0 发布标准
                                                                          ▼
                                                        4d 升 1.0、冻结 ──▶ 4e 1.0 之后的反馈（1.x）
```

| 小步 | 做什么 | 主文 | 主要命令 |
|---|---|---|---|
| [4a 出单上线](../../wiki/反馈迭代/出单上线.md) | 首发待审单、换单（以最新一轮为准，机器结果不覆盖人裁）；待审条目一格一条 | [换线上人审单](../../wiki/反馈迭代/换线上人审单.md) | `guji feedback pending`、`swap run`、`online-lists --audit` |
| [4b 收单落票](../../wiki/反馈迭代/收单落票.md) | 读票→写人裁→定字直接落 book-text→KV 结案→推库→发站核对 | [收单](../../wiki/反馈迭代/收单.md) | `guji feedback collect`、`cellvotes draft／write`、`guji db sync` |
| [4c 更新 book-text](../../wiki/反馈迭代/更新book-text.md) | 换包落 book-text（格号变时走格级对照表）、标 main 后收尾、参校本对比查漏 | [换包落book-text-增删格](../../wiki/反馈迭代/换包落book-text-增删格.md) | `guji feedback swap book-text／finish-merged`、`closeout`、`rekey-cells` |
| [4d 升 1.0、冻结](../../wiki/反馈迭代/升1.0与冻结.md) | 按 1.0 发布标准 G0–G8 检查、打 1.0、登记冻结基线 | [1.0 发布标准](1.0发布标准.md) | `guji feedback exit-check`、`char-diff`、`audit`、`freeze` |

一轮落票、出单、重跑受影响页、book-text 升版的常规操作直接做、做完报结果，见 [步骤](../../wiki/反馈迭代/反馈迭代-步骤.md)。

## 要点

- **网站只发 book-text main**；book-text 流程化 0.x 小改直接提交 `dev`，每天洛杉矶 03:30 合一次到 main。
- **人审一人裁即算**，不做多人投票或双路复核；重跑结果只算提案，不覆盖已发布文本和人裁事件。
- **单子发出后格位层不能再变**（图源 `source_rev`、切分、`manual-cells`），否则读者已投的票作废或漂移；定字层（字形库、语料、字组）可以照常升级。格号真变了只走一条路：[换包落book-text-增删格](../../wiki/反馈迭代/换包落book-text-增删格.md)。
- **停放模式**（10-29 起）：用户不再亲自审人审格，大部分册停在 v0.x 等读者投；落票按增量做，不假设「投完了」。
- 主包一天换几次别每次都追：先落票，等本书说这批稳了再换单。
- 待审单、人裁事件、book-text 格子三者怎么连，见 [00-总览/待审单-人裁事件-book-text格子](../00-总览/待审单-人裁事件-book-text格子.md)。

## 用户参与

只在「打 1.0 标签与冻结」「整册解冻」「放宽放行规则」「检查不过强行继续」「流程之外写库」时点头；对外发布（新书上网站）先问。

## 谁做

各书线自己落票、换单（ZM、QTW、SJ）；框架 GM4（原 A32，含 1.0 之后的反馈；A34 已归档）；网站侧 Web。退回：识别／定字类回第二步自动化流程，切分／书影类回 2b。
