# 新执行机开机清单

新机器（或清盘后）第一次跑 `guji pipeline … --text-id <书ID>`（默认收尾 land）前，按顺序做完下面几步。缺件不一定报错，会悄悄降级（alt 缺失、读不到字块图）。

1. 装环境：`uv venv .venv --python 3.12 && uv pip install -e ".[torch,dev]"`（cv 仓），再 `uv pip install -e ../guji-manager`。自检：`python -c "import torch, scipy, cv2"`。
2. 取模型与字体：`guji model fetch`（本机缺的模型文件从 R2 取回；相似字 `audit alt` 要 `glyph_sim_qtw_v2` checkpoint，缺了会退出 1 并说明）。
3. 同步中心库：`guji db sync -w <工作区>`。
4. 取原图：`guji source pull <册> -w <工作区>`；字块缓存 `guji cache warm --book <册> -w <工作区> [--pages 页表达式]`。land 缺字块图时会自动补拉，但**盘要够**（默认要 ≥3G 空，`GUJI_LAND_MIN_FREE_GB` 可调），超时 60 分钟会终止并报错。
5. 盘：`guji land -w <工作区> --book-text <仓> --disk-report` 看账；可删、绝不能删的清单见 `guji land --help` 与 ai-team `domain/GM/GM4/换包落地-guji-land用法.md`。
6. 环境变量：`GUJI_WORKSPACE`、`PYTHONIOENCODING=utf-8`、`GUJI_ACTOR`。
