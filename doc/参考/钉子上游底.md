# 整列钉子（manual-cells）的上游底

钉子（`feedback/verdicts/char-segmentation/manual-cells/items.jsonl`，`guji pipeline seg pin` 写）的格坐标是**列图坐标**。列图一变，坐标就对不上。写钉子时在 `input.column_basis` 记下当时的上游：

| 字段 | 含义 | 起 |
|---|---|---|
| `col_sha` | 这一列列窗记录（column_warp＋2b 文字带＋2c 剥边拼回）整条 JSON 的 sha256 前 16 位 | v0.4.74 |
| `cw_fp` | 这页 column_warp 的产物指纹 | v0.4.74 |
| `geom` | 几何底：列图坐标只由它决定（见下） | v0.6.35 |

`geom`（`seg_pin.column_geom`，与 cv `steps/_warpmap.ColumnMapper.of` 的入参一一对应）：

```json
{"v": 1, "page_w": 4296,
 "left":  [x_at_top, slope, k2, k3, y1, y2],
 "right": [x_at_top, slope, k2, k3, y1, y2],
 "top_y": 812.0, "bottom_y": 5480.0, "ruled": false}
```

- 边线六项同 cv `VLineRec`；直线 `k2..y2` 为 null，三段折线四项都有值。小数按 3 位（斜率 6 位）取整。
- `v` 是口径版本，字段含义变了才加一。

## 谁用

- `guji pipeline seg pins-stale`：有 `geom` 的**只比 geom**；几何字段变了时按钉子框在新旧列图间的实际位移判，≤3px 记 ok（v0.6.39 起，需 cv ≥ v0.9.6；outer_bar 开↔关只动外侧线，原先会误报）（文字带、剥边、判型改了不影响钉子坐标，不再误报）；没有的老钉子退回比 `col_sha`／`cw_fp`。
- cv `row_segment`（套钉子时）：有 `geom` 且与现行列窗几何不同，就用当时与现在两个列图映射把钉子格框经原图换算到新列图；最大位移 >3px 的列打 `manual_cells_remapped` 送人核。没有 `geom` 的照旧原样套（见 cv `doc/2-切字/切分覆盖.md`）。
- `guji pipeline seg pins-backfill-geom [册…] [--write]`：一次性给老钉子补 `geom`，**只补现行列窗与钉子当时 `col_sha` 一致的**（这时现行几何就是当时的几何）；不一致的先 `seg pin` 重核。

## 没有 geom 的老钉子：批量重核

`guji pipeline seg pins-recheck <册…> [--products …] [--cache …] [--write]`（v0.6.36 起）：对 active 且没有 `geom` 的钉子，在**现行列图**上逐条核：

1. 生效：现行 row_segment 那一列带 `manual_cells` 旗、格号与格框和钉子一致（不一致＝钉子改了而该页没重跑，先重跑）；
2. 钉子框不出现行列图；
3. 不压墨、不一格跨两字（cv `eval.seg_screen.pin_geometry`，同 cv `scripts/seg_pins_check.py` 第 1b 节；没有 U-Net 裁判时压墨只当提示）；
4. 格外没有成段的墨（cv `feedback.pins_check.uncovered_ink`，同第 1c 节②；压着印章只当提示）；
5. 有 cell_shrink 产物时钉子每格都出同号字格（同第 1 节）。

全过的补 `column_basis`（含 geom），history 记「重核补底」；不过的列出来人核或 `seg pin` 重钉（退出 3）。册序：全唐文 → 史記 → 脉经；殿本冻结不动（CV0 11-26）。

`seg pins-stale` 另报「未生效」：同第 1 条，比产物这一列与钉子的格（不比时间，取包会改时间），钉子改了而该页没重跑就列出要重跑的页（GM2 11-26）。
