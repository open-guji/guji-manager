# 收轮检查单（任务库 `roundcheck`，v0.4.69 起）

一轮跑完、标 main 之前每册要做的只读检查，交给任务库在执行机上跑，不再在自己容器里手跑（全唐文 11-19：45 册约 1.5 小时，容器一重启就断）。三本书（史記、全唐文、殿本）通用。口径照 QTW 收轮脚本（ai-team `domain/CV/新书登记/全唐文/收轮脚本/`）。

## 一、做什么

每册一条单，执行机上依次：

1. 取对照包（缺省 ★main）和候选包，各放一份（`pack fetch --to`，不动工作区产物）
2. 两份各跑 `guji seg check`（同页范围、同开关；缺省 `--no-defect`）
3. `guji seg gate`（带切分根因台账、书名）→ gate.md、切分未定.tsv
4. `guji products diff`（候选对 main）→ 放行字变、admit→review、review→admit、人裁翻转
5. `guji seg premain --products <候选>`（可带放行清单）
6. 候选包待审格（seed_admit `admit` 假且 `channel` 不是 excluded）：
   - **分四层**（QTW cls36 口径，判序先中先归）：1 切分（doubts 有 occluded、channel=seal、或库首位分 < 0.90）→ 3 形近字组（参校本字／库首位／5b 首位在形近字组或 NEAR_FORM_CHARS，或 doubts 有 near_form）→ 2 库缺样本（本书字形库刻例 < 5，或无候选）→ 4 其余
   - **按 `pending_reason` 计数**（同出单判法）
7. **人裁掉格**（候选包里人裁绑不上、main 里没掉的格，`人裁掉格.tsv`）与**放行字变**（两边都放行、字不同，`放行字变.tsv`；旧字是人裁或＝参校本的标「可疑」）——v0.4.74 起，11-20 殿本 PUA 线 r13／r14 教训；**人裁掉格非零结论就是「不能标 main」**，先重挂人裁（落票或重放）
8. 记下中心库 rev、字形库刻例指纹（`exemplars.jsonl` 行数＋sha），可复现

结论「通过」＝ gate 不挡、premain 无命中、且没有新掉的人裁。只读：不推库、不标 main、不存包。

## 二、交单

```bash
# 台账缺省 auto：交单这台机器从 ai-team main 取最新的 domain/CV/A22/切分根因台账.tsv（本机要有 ai-team 克隆或 gh），
# 只留本书行，随单带给执行机；执行机不用连 ai-team。
for v in $(seq -w 046 060); do
  guji_jobs submit --kind roundcheck --book $v --book-id 995ejelvk0 --cv v0.7.80 \
    --rc-pack <该册候选包标签> --rc-ledger-book 全唐文 --why "QTW e1 收轮检查 046–060"
done
```

| 参数 | 说明 |
|---|---|
| `--rc-pack` | 候选包标签（必给；不能写 main） |
| `--rc-main` | 对照包，缺省 main（取 ★main）；要比别的包写标签 |
| `--rc-ledger-book` | 台账里的书名：殿本／史記／全唐文。给了就带台账 |
| `--rc-ledger` | 缺省 auto（从 ai-team main 取）；可给本地 TSV；`none` 不带台账 |
| `--rc-allow` | `seg premain` 放行清单（本地 TSV，随单带上） |
| `--rc-set` | 按单覆盖分层配置（可多次）：`seg_defect=true`、`order=seg,group,lib`、`cov_min=0.9`、`lib_min=5`。盖过执行机上的 workspace.yaml，进指纹（v0.4.72 起） |
| `--pages` | 只查这些页（seg check／diff／premain 同范围；待审计数总是全册） |
| `--cv` | 必填（执行机按它装 cv、备工作区）；写本轮的 cv 版本 |

## 三、看结果

```bash
guji_jobs show <号>                                  # 一行结论在最后一条进展；结果里有 gate.md、premain、按原因计数
guji round-check --collect 6001-6015 --out rc-e1    # 一批收成一份
```

`--collect` 出：`汇总.tsv`（每册一行：结论、gate、回退列、新页级错、已知未清、未挂台账、premain、全册格、待审、四层各几格、main 待审、翻转数、中心库 rev、字形库指纹）、`待审按原因-合计.tsv`，各册目录下 gate.md、切分未定.tsv、premain.tsv、pending_by_reason.tsv。有不通过或没结果的册退出 3。

本机也能直接跑同一套（调试、单册急用）：

```bash
guji round-check 046 -w <书仓> --pack <候选包> --ledger auto --ledger-book 全唐文 --out rc/046
```

## 四、书级配置

工作区 `workspace.yaml` 加一段（不写就用缺省＝全唐文 cls36）。

**执行机读的是中心库里的 workspace.yaml，不是书仓里的**：准备时书仓先跟到 origin/main，接着 `guji db pull` 用中心库那份 workspace.yaml 盖掉检出里的。所以改了配置要：

1. 书仓里改 workspace.yaml（留档、走 PR），**并且** `guji db push -w <书仓>` 推进中心库（只改书仓不生效：史記 11-20 #5968 书仓开了 `seg_defect: true`，单子照缺省关，42:137:4、42:28:3 两处 CLIP 真错漏报）；或者
2. 交单时 `--rc-set seg_defect=true` 按单覆盖（不用推库，立刻生效，写进单子定义）。

每单实际用的配置看 summary.json 的 `layer_config`（覆盖了哪些看 `layer_overrides`）；交单前先核一单。

```yaml
round_check:
  order: [seg, group, lib]   # 判序：seg＝1 切分、group＝3 形近字组、lib＝2 库缺样本；都不中归 4 其余
  cov_min: 0.90              # 库首位分低于它算切分
  lib_min: 5                 # 本书刻例少于它算库缺样本
  seg_defect: false          # seg check 跑不跑同字对照切坏检测（慢）
```

本机 `guji round-check` 读本机工作区的 workspace.yaml，也可 `--set seg_defect=true` 覆盖。

## 五、注意

- 执行机的 manager 要 ≥ v0.4.69（执行方领单前自更新到 manager main）。
- 单的指纹含台账全文：台账改了再交同一册不会被判重复；台账没改又想重跑加 `--again`。
- 实测（11-20，全唐文 045 前 5 页）：结果与 QTW `tot.py`／`cls36.py` 全册数一致（待审 63／29,572；2 库缺样本 17、3 形近字组 16、4 其余 30）。
