# 轮报告与验收工具（`guji-manager iterate`）

> 状态：现行（2026-11-05，A31）。落实[降人审迭代框架](降人审迭代框架.md)的工具缺口 T3、T6、T7、T8、T9。代码在 `guji_manager/iterate/`，只读文件（pending-stats 输出目录、tsv、yaml），不连库、不依赖 cv。

## 一览

| 命令 | 对应 | 干什么 | 什么时候用 |
|---|---|---|---|
| `iterate round-report` | T7 | 本轮 vs 上一轮：两个数、按 pending_reason、按册、按列、回退清单 | 每轮重跑完（框架 8.2 步 7–8），标 main 前 |
| `iterate gold` | T8 | 金标登记、校验、抽样、放行子集验收 | 新放行类别上线前（R3）；越过参校本按书按组抽 30 格 |
| `iterate audit` | T9 | 每轮滚动抽检台账：抽 30、记对错、累计错误率上界 | 每轮放行后 |
| `iterate leverage` | T3 | 给待审格分卡打分，出人审点选页的出卡顺序 | 派人审页前（R4） |
| `seg gate`（`guji seg gate`） | — | 切分不回退闸：新旧两份 `guji seg check` 比，回退列或新页级错退出 3；出 `切分未定.tsv` 给下游跳过 | 每轮重跑完、标 main 前（A22 11-13，见[切分快筛](切分快筛.md)十二节） |
| `iterate freeze` | T6 | 三书冻结日历；合 PR 前查撞不撞冻结 | 每个会改 dev 的 PR 合并前；每轮冻结/解冻时 |

## 一、轮报告

```
guji-manager pending-stats --out out/r5                       # 先出本轮统计（cells.tsv 现在带 ref、top 两列）
guji-manager iterate round-report --cur out/r5 --prev out/r4 --label r5 --prev-label r4 \
    [--released 放行.tsv] --out out/r5-report
```

输出 `report.md`（给人看）＋ `by_vol.tsv`、`by_col.tsv`、`by_reason.tsv`、`regress.tsv`。内容：
- **两个数**：首审人审率；净人审队列＝待审 − 单列（hard_pair、occluded_no_ref）− `--released` 已放行格。
- **回退清单**：本轮待审、上一轮不在待审的格。按册、按列汇总——整列/整页回退多半是切分变了，不是字的问题。
- **灯**：回退格占上一轮待审 ≥5% 红（退出码 2，不标 main）、≥2% 黄；待审格号与上一轮重合率 <90% 的册提示「可能变列」（S 轮逐册比格号）；总数反升、非正文格数变了给黄。
- **收口单草稿**（第六节）按 pending_reason 给归宿，含「交接单·极难字」栏（hard_pair 列进 v0.1 交接单，不另行通知）。
- 不含**放行字变**和**人裁丢失**：这两项要拿上一轮包与本轮包做 A/B，仍走验收标准里的回归步骤。

## 二、金标

**金标放哪（11-05 定）**：ai-team 仓 `domain/CV/质检/gold/`（私有仓，标注数据不进公开的 manager 仓；命令的 `--root` 指向它的检出目录）。A22 已在 `殿本/_index.yaml` 登记切分金标指针。

只收**放行类别的格级金标**：`gold/<书>/<pending_reason>.tsv`，列 `cell_id pack ctx_hash pending_reason label labeler labeled_at source note`（cell_id 为 `册:页:列:行`）。label 是单字，或 `@seg`／`@unreadable`／`@human`（对自动放行一律算错）。金标由用户标注，**不进任何提示词**。A23 的 5a/5b 等组件评测金标留在 open-guji-dataset，不复制，只在 `gold/<书>/_index.yaml` 登记指针（name kind path version frozen_at owner used_for）。

```
guji-manager iterate gold sample --cells out/r5/cells.tsv --reason group_abstain --n 30 --root gold --book sj --out pick.tsv   # 抽 30 格去标（排除已有，按册轮流）
guji-manager iterate gold add --root gold --book sj --cls group_abstain --file 标注结果.tsv --labeler sheldon                    # 登记；与已有答案冲突会拒绝
guji-manager iterate gold validate --root gold                                                                                    # 格式、重复、冲突、不足 30 格的类、_index.yaml
guji-manager iterate gold eval --root gold --book sj --cls group_abstain --released 放行.tsv --out 验收.md                      # 放行子集对金标
```

验收口径（框架第五节）：放行 <100 格抽 30、>300 抽 100、>1000 抽 200；**0 错且命中数够才通过**，同时报错误率 95% 上界（0/30 ≈ 10%）。放行文件带 ctx_hash 时与金标比对，不一致算「金标过期」不计命中。100–300 格文档未写，工具取 60，可在 `common.required_sample` 调。

## 三、抽检台账

目录 `audit/<书>/ledger.tsv`，列 `round vol cell cls verdict checker note date`，verdict 为 ok/bad/skip，cls 如 `L2:group_abstain`。

```
guji-manager iterate audit sample --root audit --book sj --round r5 --cls L2:group_abstain --released 放行.tsv --out 抽检.tsv   # 抽 30，排除以前抽过的
guji-manager iterate audit add --root audit --book sj --round r5 --cls L2:group_abstain --results 结果.tsv --checker A31
guji-manager iterate audit summary --root audit --book sj --out 台账.md      # 本轮有 bad → 红灯，退出码 2：停标 main，收紧后重测
```

## 四、杠杆排序

```
guji-manager iterate leverage --cells out/r5/cells.tsv --out out/r5/leverage --top 100
```

一张卡＝同 pending_reason＋同一对（参校本字, 库首位）；`lib_sparse_dissent`（L02）只按参校本字并卡（`BY_REF`，11-06 起：参校字库里没几个刻例时库首位是乱选的）。顺序：tier 0 第一次进库（`lib_missing`、`lib_sparse_agree`，用户 11-03 定必须人裁）→ tier 1 其他走人审的 → tier 2 底线/留后（hard_pair、occluded_no_ref、unknown，不出点选页）；同 tier 内按「同对格数＋2×(涉及册数−1)＋同字头全书格数×0.1」。输出 `leverage.tsv`（卡片顺序）、`cards.tsv`（每格归哪张卡，人审页按卡取格）、`report.md`。人审页模板见[人审页模板](人审页模板.md)。

## 五、冻结日历

日历是一个共享 yaml，放 ai-team `domain/CV/质检/迭代降人审框架/冻结日历.yaml`（A31 维护，各线只读；时间洛杉矶）。

```
guji-manager iterate freeze add --file 冻结日历.yaml --book dianben --from "2026-11-05 10:00" --to "2026-11-05 22:00" --note "r5"
guji-manager iterate freeze list --file 冻结日历.yaml
guji-manager iterate freeze check --file 冻结日历.yaml --books dianben,sj --steps seed_admit    # 撞了退出码 3
```

- **只冻结 S 轮**（11-05 框架定）：D 轮期间各线照常合决策层改动；S 轮冻结期不合改切分指纹的 PR（缺省按结构步查：border_detect、cell_shrink、row_segment、页型、图源、语料、库快照）。格号变化通知名单缺省 A22 A23 A30 A20，`check` 撞冻结时一并打印。
- **规矩**：合到 cv dev 的 PR，描述里写「影响的书／Step／指纹变化」，合并前跑 `freeze check`。cv 的 PR 模板加这一行由 A20 办。
