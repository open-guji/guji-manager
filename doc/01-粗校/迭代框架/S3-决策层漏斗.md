# S3 决策层漏斗（约 0.4% → 目标）

> [总览](../降人审迭代框架.md) · 上一步 [S2](S2-配置爬降.md) · 下一步 [S4](S4-收口出v0.1.md)

**目的**：机器原理上定不下的格，按待审原因（`pending_reason`）分流给算法、AI 和人审页。格从便宜的层往贵的层走，上一层放不掉才进下一层。

## 五层

| 层 | 做什么 | 放行条件 |
|---|---|---|
| L0 配置 | 开关、白名单、码位结局、页型 | 回放 0 错 |
| L1 算法 | 文本层取字＋私用码表、book_knn／near_knn、规则（取参校本字须两次 high）、切分归因 `seg_causes` | 留出集 0 错 |
| L2 AI 文意 | 算法给候选，对话会话只读文意（前后 20 字）在候选里选；A/B 两路 | 两路都 high 且同字、字在候选里，**并且**字形分够（殿本 ≥0.95，各书按金标标定）或有 ≥2 个独立来源；越过参校本只放本书白名单组 |
| L3 复核 | 对 L2 放行抽样盲读；mid 的格加第三次读 | 见 [准确率守则](准确率守则.md) |
| L4 人审页 | 预选好答案的点选页，按杠杆排序（同字全书格数多、第一次进库、影响多册的先上） | 人裁；结果回流成刻例、白名单、码位、金标 |

**L4 不是兜底，是产出**：每个点选结果都要回流，下一轮少审。

## 去向速查

`pending_reasons.yaml` 的 route 为准：

- **L2**：Z01–Z05、N01、L02、P01／P02（P 类先过 L1 规则）。
- **L1**：R01 文本层取字（书没有文本层则 L4）；L04／L05、D01（D01 先 `stain_pages`）。
- **L0**：Z06 码位结局；N01 先试 `follow_ref_seen` 白名单；R02 先 `symbol_ref_blank`，剩下的进 L4（只读文意判不了）。
- **L4**：L01、L03（第一次进库）、V01（异体按刻形定）、D02、S04、X*。
- **先归因再派**：S01–S03。
- **留后**：H01（日曰、己已巳），统计单列，只列进 v0.1 交接单。

## AI 统一审（不调 API）

每轮出清单后、D 轮前：`llm_queue export` 导出待裁 → 对话会话逐行判 → `import --model session` 写进裁定库 → 推库后从 seed_admit 重放。裁定键是（组、提示词版本、前后 20 字窗口哈希），不含格号，重切后仍能命中。

**大模型不看图放行**：字形一致由算法（字形分、字体渲染分）作证；大模型看图只给人审页做预标注。

## 借库备选

两本书字体不完全一样，不出共享库（sheldon 11-05）。做法是本书库为主，别的书的库作备选：

- 只借人裁刻例（`glyph_lib.borrow: [{from, scope: human, pin: N}]`），钉快照号；
- **备选库不当证人**：L2 的字形证人、「验证整理本字」只认本书库；借来的命中最多到 unsure，不能单凭它放行；
- 先单向（如史記←全唐文），两边都钉快照号之前不互借；
- 换借库单独一轮，从 glyph_match 起重跑。

方案原文：ai-team `domain/CV/字形领域/借库参照方案-本书为主另一本备选-2026-11-05.md`。

## 用户点头

- **R3 新放行类别上线前**：金标抽样页（`gold_sample`，30–60 格），只标对不对。每类 15–30 分钟。
- **R4 码位、规则、第一次进库的字**：`codepoint`、`pair_whitelist`、`char_card` 点选页。

用哪种页见 [人审页模板](../人审页模板.md) 第六节。

## 出口

到本书目标线；或漏斗各层每类都至少跑过一轮，且轮收益 <3%。
