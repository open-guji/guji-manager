# 数据与跟踪

> [总览](../降人审迭代框架.md)

**在哪看**：open-guji.com/admin/text。每本书展开后默认显示「迭代轮次」：首审人审率折线（虚线是本书目标）和轮次表；「各册」是分册明细。书头和顶部统计都取最新一轮。数据在中心库 `progress` 表，打开页面时实时读取。

| 何时 | 看什么 | 怎么来 | 存在哪 |
|---|---|---|---|
| R0 | 本书目标人审率 | 用户定 | `progress.metric` rounds／`target` |
| 每册标 main | 这册包口径人审率；这一轮书级汇总 | 钩子自动跑 run.py `--push-progress`，再跑 `iterate auto-round` | `progress.volume.extra['cv.pack']`；rounds／`r<N>` |
| 每轮验收 | 净队列、回退、主要变化、各层放行、抽检、审阅用时、结论 | `iterate round-report … --push-progress <书>` | rounds／`r<N>`.detail |
| 补历史 | 旧轮次 | `iterate push-rounds --json … --write` | 同上 |

- **自动填**按包标签里的 `-rN` 段认轮次。标签里没有这一段的书（如 `jobNNN`）不会自动收，要靠 round-report 手写。
- 人工字段（日期、结论、备注）不会被自动填覆盖。
- 作废的轮也记一条（verdict=rejected），页面画成空心红点，不当作「比上轮」的基线。

轮次字段：`kind`(S/D)、`date`、`cv`、`pack`、`vols`、`cells`、`pending`、`net_queue`、`gain`、`regress`、`released`{L0..L3}、`audit`{n,err}、`top`、`human_min`、`verdict`、`note`。字段的详细说明见 open-guji-site `docs/text-progress.md`。
