# 01 粗校：从开书到 v0.1

> 现行：2026-11-05（A31）。原「开新书」一步已并进来（目录序号随之前移），开书到 v0.1 是一个完整流程。

## 目标

从书目条目开始，把一部新书做到 book-text 文本线 v0.1（0.1.0）：原图进 R2，册进中心库，切分试跑，字形库冷启动，整册跑完，再一轮一轮把人审率压到本书目标线，最后收口。精校、点校不在内，只列交接项。

**先看总览**：[降人审迭代框架](降人审迭代框架.md)（目标、五个阶段、用户在哪点头、判停）。
