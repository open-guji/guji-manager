# L01 benchmark

> [README](README.md) · [流程与参数](流程与参数.md)

目的：给 L01 定几个能反复量、换书可比的指标，改动之后重量一次看有没有进步，也让下一本书一键体检。

## 一、体检指标（不需要金标，`tools/l01_profile.py` 直接出）

| 指标 | 含义 | 好的方向 |
|---|---|---|
| `l01_share` | L01 格数占该书待审比例 | 下降 |
| `entry2_share` | ②入口（首次入库，`all_zero` 且无 `lib_miss`）占 L01 比例 | 说明首次入库压力，人裁一次后应掉 |
| `ref_blank` 占比 | 无对位格占 L01 | 下降（它应归切分类） |
| `5b_top1/top3/top5` | 有整理本字的 L01 格里整理本字在 5b 前 N 名的比例 | 越高，放行上限越高 |
| `coord_only` | 只有坐标对位的格数 | 对位覆盖 |
| `cov` 分布 | 库首位覆盖率中位与分位数 | 看是糊图还是首次入库 |
| 同字头合并数 | 去重后的字数 | 人审工作量 |

## 二、质量指标（需要金标）

1. **放行精度**：每书抽 30 格建金标（`review-pages build` 的 gold_sample 页型，人看图判是否整理本字），候选放行规则在留出集上**错放 = 0** 才允许缺省开。
2. **放行召回**：规则能放行的格占整理本字清晰可认格的比例。
3. **回放**：规则开前后各跑一次待审统计（`guji-manager pending-stats`），确认只把待审挪到放行、不改已放行格。
