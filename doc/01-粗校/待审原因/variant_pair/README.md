# V01 `variant_pair`：异体字

> [待审原因总览](../README.md)

**一句话**：两个字是异体，要确认本书刻的是哪个

## 定义与判定

- 大类：异体（V）；判定顺序 priority 55（小的先判，第一条命中即主原因）。
- 判定依据：整理本字与库首选（或前五）是异体对，但不在字组里；或 why 含 ref_lib_variant/variant_indirect/replace_form/channel_off
- 去向：一定人审（route `human`）；最终谁看：人；网页卡片 `pick`。
- 负责改算法／数据：A24。
- 旧字段对应：{"cause": ["B"], "cls": ["variant"], "taxonomy": ["M1", "M2"], "v2": "V 组外异体对"}

## 常见成因

参校本字与库首选是异体对，不在字组里。

## 怎么处理

1. 人审：按刻形定用哪个字（异体看刻形）。
2. 同一对异体成批出现时用 `codepoint` 页一次定全书。

## 回流与防再犯

结论写码位表或异体边表，下一轮自动放行。

## 不要做

不要靠文意定异体。
