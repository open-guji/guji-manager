# L05 benchmark

> [README](README.md) · [流程与参数](流程与参数.md)

目的：给 L05 定几个能反复量、换书可比的指标，改动之后重量一次看有没有进步，也让下一本书一键体检。

## 一、体检指标（不需要金标，`tools/l05_profile.py` 直接出）

| 指标 | 含义 | 好的方向 |
|---|---|---|
| `l05_share` | L05 格数占该书待审比例 | 下降 |
| `releasable`／`releasable_share` | A1＋A2（按 `--min-cov`、`--no-group-top` 回放）能放行的格数与占 L05 比例 | 越高，放行上限越高 |
| `classes.C`（无对位） | 整理本这一位没字的格，应分流到 S04／R02／非字 | 下降到 0 |
| `char_ne_ref_share` | 有整理本字的 L05 格里，上下文字≠整理本字的比例＝闸拦对率 | 接近 1；若明显低于 1，说明闸在拦对的字（需看图） |
| `top_attractors` | 库首位出现最多的字 | 集中度越高，越该查库刻例 |
| `ref_lib_n_buckets` | 整理本字在本书库的刻例数分布 | 0 例多＝首次入库压力 |
| `ref_in_5b.top1/top3` | 整理本字在 5b 前一／前三 | 越高，放行上限越高 |
| `cov` 分位 | 库首位覆盖率分布 | L05 应落在 0.85–0.90（罕用 0.95） |
| `page_no_align_cells` | 整页无现役对位的格 | 坐标支不可用的量 |

## 二、质量指标（需要金标）

1. **放行精度**：A1＋A2 每书抽 30 格（殿本、史記；全唐文太少全看），`review-pages build` 的 gold_sample 页型，人看图判是否整理本字，**按册留出，错放 = 0** 才允许册 yaml 打开。
2. **放行召回**：规则能放行的格占「整理本字清晰可认」格的比例。
3. **回放**：规则开前后各跑一次 `guji-manager pending-stats`，确认只把待审挪到放行、不改已放行格。
