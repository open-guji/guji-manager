# L05 `garble_gate` 流程与参数

> [README](README.md)（介绍与配图）· [benchmark](benchmark.md)（怎么量好坏）

本文回答：**什么样的格会进 L05、判据和参数各是什么、怎么放行、新书上手怎么做。** 代码事实来自 guji-manager `review/reasons.py`、cv `steps/seed_admit.py`（seed_admit 1.45，2026-11-06）。

## 一、一格怎么走到 L05

```
glyph_match ─ rare_candidates(5b) ─ align_ref ─ context_decide ─ seed_admit ─ pending_reason
 (库匹配)      (字体嵌入前十)      (对位/坐标)   (上下文排候选)   (放行通道)     (reasons.py)
```

1. **glyph_match**：格图与库刻例逐个比，取覆盖率 cov。`same` cov ≥ 0.996；`unsure` 0.85 ≤ cov < 0.996；`diff` 所有候选 < 0.85（`COV_LOW`，即 L01）。L05 的格全是 `unsure`。
2. **context_decide**：`unsure` 的候选交上下文排序。候选只来自库，L05 格 199/238 只有库首位 1 个候选，margin 恒为 1.0——所以「上下文定字」＝库首位。
3. **seed_admit 的 context 通道**：上下文字满足 margin 够、没有被互证／空白／过高／单笔画等闸拦下，才放行。其中乱码闸 `context_garble_guard`（缺省开）：
   - 取证人 ＝（整理本对齐字、坐标对位字、前几名 OCR 候选），有一个与上下文字语义相同（`vmap.semantic` 相等）就是**有背书，不拦**；
   - 没证人时：库首位 cov < `context_garble_cov`（0.90）→ `ctx_garble_shape`；罕用码位字且 cov < `context_garble_rare_cov`（0.95）→ `ctx_garble_rare`；`context_garble_run`（缺省 0 关）；
   - 命中则不放行、落人审，字照旧。
4. **shadow_veto**（缺省开）：对**已放行**的格，影子模型很有把握选了另一个字就降回待审（`shadow_conf` 0.8）。
5. **补放通道**（只碰仍待审的格，只升不降）：
   - `rare_ref`（缺省开）：现役对位字（difflib）＝5b 首位 → 放行为整理本字；
   - `rare_ref_coord`（缺省开）：现役对位没有这一格时，用**坐标对位字**当整理本字再走一遍；多四道护栏，见下；**只在整页现役对位非空时才跑**（seed_admit `if p.rare_ref and p.rare_ref_coord and amap`）。
6. **reasons.py**：仍待审、**整理本这位有字**、格上有 `ctx_garble_shape`／`ctx_garble_rare`／`shadow_veto` → L05（priority 52）。排在 L01（51）之后，所以同时带「库里没有」的归 L01。

**为什么 L05 的格补放不上**：L05 格的现役对位多半为空（232/238 没有 `cur`），走坐标支；坐标支的第二道护栏 `cov ≥ rare_ref_coord_min_cov`（缺省 0.90）把 cov 0.85–0.90 的全挡了。放宽后再被「库首位在字组里」挡 12 格。

## 二、参数表

| 参数 | 缺省 | 作用 | 本次看到的 |
|---|---|---|---|
| `context_garble_guard` | 开 | 没证人时拦乱码 | 拦对 194/196，不动 |
| `context_garble_cov` | 0.90 | `ctx_garble_shape` 的 cov 线 | 不建议放宽（会把库首位错字放行） |
| `context_garble_rare_cov` | 0.95 | `ctx_garble_rare` 的 cov 线 | 11 格，罕用吸引子 𫎇、𨽾 |
| `shadow_veto`／`shadow_conf` | 开／0.8 | 影子否决已放行格 | 7 格 |
| `rare_ref`／`rare_ref_coord` | 开／开 | 5b＝整理本字（含坐标对位字）放行 | |
| **`rare_ref_coord_min_cov`** | **0.90** | 坐标支库首位 cov 下限（书级） | 放到 0.85 放 79 格 |
| **`rare_ref_coord_group_top`**（新，cv#1204） | **关** | 库首位是字组成员、坐标对位字不在组里也放 | 再放 12 格 |
| `rare_ref_nf*` | 开 | 坐标支放宽 `near_form`（BMP 字、库刻例≤2…） | |
| `lane_variant_topk` | 3 | 库前三候选里有整理本字异体则不放 | A3 里 4 格 |

书级参数写在册 yaml 的 `params.seed_admit`；册 params 压过管线 yaml（`guji book show --effective` 看）。**关着的开关不进参数 dump，产物指纹不变。**

## 三、放行判据（离线回放口径）

一格被放行当且仅当（A1／A2）：

1. 整页现役对位非空；
2. 坐标对位字非〓、非空；
3. 库首位 cov ≥ `rare_ref_coord_min_cov`；
4. 坐标对位字不在任一字组；库首位不在字组（A2 在开 `rare_ref_coord_group_top` 时放过这一条）；
5. 无 `group_flow`／`shadow_veto` 疑问，无 `_RARE_REF_HARD` 疑问（occluded、excluded、near_form、context_blank_cell、context_tall_cell、form_open、approx_exemplar），无护栏（never_match／conflict／timeout）；
6. 库前三候选里没有整理本字的异体，库首位不是整理本字的异体；
7. **5b 首位＝坐标对位字**。

## 四、新书上手步骤

1. 取数：假工作区（`workspace.yaml`＋`.central.json`）、`GUJI_DATA_HOME`、`guji db pull -w <ws>`；
2. 跑体检：`python tools/l05_profile.py --ws <ws> --text <书 id> --out out/<书> --jobs 4`，看 `summary.json` 里 `classes`、`releasable`、`char_ne_ref_share`（闸拦对率，应接近 1）、`top_attractors`；
3. 抽金标：A1＋A2 每书抽 30 格（按册留出；史記夹注、全唐文等小书全看），看图判是否整理本字；错放 0 才往下；
4. 册 yaml 设 `rare_ref_coord_min_cov`（试 0.88／0.86／0.85）和 `rare_ref_coord_group_top`，用 `--min-cov` 回放不同取值；
5. 重跑由 A31 冻结后统一做，不自己重跑整册。

## 五、没做的与待定

- C 类（无对位，42 格）：已改，L05 要有整理本字，无对位的落 R02（sheldon 11-06 定）；圈点／碎片再细分交 R02；
- B 类候选集扩展（库首位＋整理本字＋5b 前三）：同 L01 方案 2，先做金标；
- 整页无现役对位的坐标放行（A3 5 格，L01 同题）；
- 吸引子字的库刻例清理（刪、冊）：没实验。
