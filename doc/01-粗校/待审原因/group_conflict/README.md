## 一、什么情况判成 Z02

manager `review/reasons.py` `_group_kind`（priority 41）：格带 `group` 证据，且解法给了 **≥2 个不同字**，或 `why` 是 `conflict／joint`。cv 里有三条路会走到这里：

| 路 | cv 位置（`open_guji_cv/groups/flow.py`） | 什么情况 |
|---|---|---|
| ① 复核降审（`mode=review`） | 页末复核已放行格 | 任何一路解法给了与放行字不同的字，或解法之间 `conflict`，又没有豁免（`review_weak`、`shape_ref_ok`、`abstain_ref_ok`…）→ `group_flow_disagree`，`decision=demote`。与 Z03 的区别：这里**几路解法给的字不一样**（Z03 只有一个字）。 |
| ② 补放冲突（`mode=lift`） | `decide()` 里解法给了不同字 → `conflict`（文意×字形，如 ctx 说二、ids 说一）→ 不放，格留待审 | 库首位字还没放，字组想补放，但几路不一致。 |
| ③ 联合判（`mode=joint`） | `decide_joint()`：共字组（日曰目、门问、辶族、于千子、山由出…）联合判，**搭档组没有同意也没有明说「其他」**就 `joint` | 本组定了字 X，X 不在搭档组里，搭档要「明说其他（各遍 high）」才放；搭档弃权、文意缓存没有、码位解法给别字都会卡。 |

去向 `route=llm`（大模型统一过一遍，只收 high，其余回人），负责 A24。

## 四、深挖：为什么会这样

1. **L1 规则是二字组合，字组只有两个字时误判不少。** 全册 39.5 万个带组证据的格里（`scan_groups.py`、`rule_audit.py`），每条规则命中的格拿整理本字当真值，`jys` 之外（己已巳整理本不分，不算）冲突最多的：`zh-曾經` 命中 92、冲突 26（附會經義、附會不經、理會、誤會、體會）；`yt-圓` 33／10（圖形、圖周禮）；`rm-日` 17／7（每目＝每个条目）；`yh-還朝` 194／15（補遺原目、無遺報、往往遺議）；`yh-遺文` 1873／22（往還詔、放還老）；`js-申-l1` 320／5（左傳甲午、引甲帳、又甲聲）。已收窄 7 条（第七节），全册冲突 1187→1119，好命中只少 7 个。
2. **ids、yr_bars 是弱票，却和文意同权。** 面而、傳傅、圓圖这类在殿本刻本里字形差得远，图上一眼分得开，但 ids 在糊字、墨团上给 0.6–0.95 的 margin 也会错（傳→傅 0.95）；一二被切残后 yr_bars 数横几乎必错（11／12）。复核「任何一路反对就降」，所以 B1 28 格全是错降（27／27 放行字对）。
3. **入人八（C 类）的文意不独立。** rr 组目视 19 格里文意给了字：对 9、错 10；C 类里读得定的 16 格，放行字对 15、文意对只有 1（vol94:66:1:21「不[入]自列名」，整理本、库、图像两路都是人，文意说入才通）。文意错得很明显的有「宋人百家詩」读八、「敵人圍蔡亢」读入。rr 的文意是大模型缓存 high，没有 strong、没有二审；rr 图像（rr_img、ids）对入人也不稳（ids 判错的 margin 最高到 1.67，左撇长短才是区别，殿本刻本入人都有变形）。所以 rr **不能**用「图像两路＋整理本压过文意」自动放，也不能进 `dissent_keep`；要么人看，要么改文意读法（窗口、提示词、二审小组），**不是 flow 规则能解的**。
4. **联合判卡在搭档没有裁定（D2 13 格）。** 日曰目 rm＋ry＋mz 三组联判，搭档 ry 明说「其他」，但 mz 的文意缓存是 `llm_pending`；门问 men 的搭档 wj 同；于千子 zy 的搭档 yz 是 `cache_miss` 或 `llm_api_400`（旧 API 调用留下的失败占位，管线不在线调，永不会变）。这些格是**没问过**，不是打架。导出待裁清单（`feedback/llm_queue`）开干净会话裁，写回裁定缓存即可。
5. **机器字（库首位）错的占 2/3（lift、joint 里放行字错 33／对 16）。** 门族、辶族、于千子里库首位常给个相近的字（巡→進／遺、于→千、閣→間、山→由），整理本对、文意对。卡住只是因为补放（decide）把图像路和文意看成同权的几路：整理本这一票没算进去（`lift_ref_agree` 只在放行字与整理本不同时拦，没有「整理本和本组解法一致就取它」这一支）。D1 28 格就是这样。
6. **异形被算成「不同字」（A 10 格）。** manager `_group_kind` 数 `sol` 的不同字时不做书级码位归一；象／𧰼、寇／㓂、會／㑹 是同字异形（组内本来就暂归一），算成了 ≥2 个字。其中 kgc 2 格 `decision=admit` 已放行，还带着 Z02。
7. **不能因为整理本对就全信整理本。** 整理本字对 99／112，错 13；ts 士土 vol13:8–10 相土（整理本作士）就是坐标对位错、量横对。所以 `ref_pair` 要求**整理本字＝本组某路解法给的字**，且反对的必须都是图像路——ts 这 3 格的 bars 没有 margin，被挡住（不会错放）。
