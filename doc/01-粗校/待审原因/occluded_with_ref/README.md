## 一、判定条件

代码：`guji_manager/review/reasons.py`，优先级 11（第一条命中即主原因）。

```
遮挡      格上有 occluded 疑问码，或 evidence.occluded（cv seed_admit 的 occluded_gate 写的）
D01 =     遮挡 ∧ 整理本这位有字 ∧ 不是「遮挡格而整理本字在 日曰己已巳」
H01 ←     遮挡 ∧ 整理本字 ∈ {日 曰 己 已 巳} ∧ 机器字没有或也在这五字内     （11-08 起，见第五节）
```

**「遮挡」怎么来的**（cv `steps/occlusion.py`、`seed_admit`；细节见 cv `doc/design/印章遮挡格-判据与放行.md`）：整页检测到大印／污渍块（热格连通块≥12 格、跨≥3 列、峰值密度≥8），印框内的格再看格内背景噪点（`occluded_seal_min_noise` 4）；或小印与格重叠。命中的格**不进任何放行通道**，默认字取整理本字（坐标对位优先），字形一律不进字形库。

**放行通道 R5**（`lane_seal`，缺省开）：默认字来自坐标／现役对位 → 放；护栏依次是题列整列拦（题列套语除外）、异体护栏、**库否决**（库首位 cov≥0.95、与默认字不同、不是异体对、默认字不在库前二、默认字库内刻例≥2）、整页错位护栏。这些护栏拦下的格就是 D01。

几个值得记住的事实：

- **库否决 30 格里，库首位覆盖度分不开对错**：整理本对的 22 格 cov 0.950–0.999（中位 0.959），整理本错的 4 格 0.950–0.970（中位 0.963），完全重叠。A32 11-06 的结论（不能靠覆盖度放）第 7 轮再次成立；整理本字真错率这次是 5／33＝15%，比 A32 报的 3–6% 高（首叶集中、作者行／夹注多），所以**不能放宽库否决**。
- **「遮挡」不都真脏**：6 格噪点密度 <4（0.26–0.61；vol27 137、vol31 83、vol39 103、vol57 147、vol63 208 的格）仍标遮挡，原因是小印重叠分支不看密度。其中 3 格是切偏／半截（D02 里的 C 类），1 格已改文本。放宽对降量帮助很小（见第六节）。
- 己已巳 19 格上，库首位是印泥下的噪声：15 格首位在组外（唐、臯、包、道、卑、目、臣、色、遇、厯、遒、百、量、緖、巴），覆盖度全 <0.9；只有 4 格首位在组内。所以现有 `fold_occluded`（要求库首位也在组里）只接得住 4 格。

## 三、整条流程（下一本书怎么快速做）

1. **现算**：`doc/01-粗校/待审原因/ref_lacuna/scripts/按码现算.py --codes D01,D02,H01 --books siku --out <目录> --glyph-db <glyph.db>`（装法见该脚本头：假工作区、`psycopg[binary]`、`websockets`、`GUJI_DATA_TOKEN=$GUJI_DATA_TOKEN_READ`）。出 `cells-occluded_with_ref.tsv`／`-occluded_no_ref.tsv`／`-hard_pair.tsv`。
2. **取证据**：每格的 seed_admit 产物里有 `evidence.occluded`（密度、默认字来源 via）、`lane_skip`（库否决的 cov、库首位、why）、`fold_pending`。
3. **裁图看图**：`scripts/d_crops.py` 逐册拉 ★main 的 cell_shrink 和书影，按 `bbox_page` 裁格；`scripts/d_sheet.py` 每 18–20 格拼一张（格图＋整理本字＋库首位＋整理本前后文）。可疑格再放大对比。
4. **分类**（每格只下一个结论）：J 己已巳族、R 整理本字对、E 整理本字错（写图字）、S 对位错位、C 切半截、? 看不准。上下文通顺性是最快的旁证，但**只作旁证**，定字以图为准。
5. **落金标**：`benchmark/D-gold-*.tsv`（册、格号、类、图上读、备注）。
6. **回流**：E 类改 book-text（流程见 ai-team `待审原因深挖/D01-方法与流程.md` 第四节）；J 类走 H01；S 类交 A22；R 类留人审预选整理本字。
7. **验收**：`scripts/d_bench.py <现算目录> <金标>`，三条（J 全归 H01、H01 不混非 J、其余数不变）。

## 五、这次改了什么（11-08）

1. **guji-manager `reasons.py`**：遮挡格、整理本字在 日曰己已巳、机器字为空或也在组内 → `hard_pair`（H01），不再落 D01／D02。理由：这一格就算没有印章也只能按文意定组里哪一个，留在 D01 只会让人看一遍图又定不了。只改分类，不放行，不动 `pending_reasons.yaml`。第 7 轮现算：D01 52→33，H01 +19（殿本这 41 册）；金标回放 J 19/19 归 H01、非 J 0 误归（`d_bench.py`）。
2. **cv seed_admit 1.67** `fold_occluded_lib_max_cov`（缺省关）：让这 19 格进折叠组的「字待文意」状态，将来 H01 的文意裁定（干净会话读，写裁定库，不调 API）一并放行。单测覆盖；**没做整册回放**，开之前先用 `fold_pending` 数量对一遍（预期 19）。
