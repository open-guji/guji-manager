## 二、金标和基线读数

**金标来源**：三书 ★main 包里「形近处境」的格（候选前三或机器字含手工形近表字，或库护栏 conflict／never_match；不管放行没放行）中，**产物里 `provenance=human`／`channel=human` 的格**——即曾经停在待审、被人裁过的格。真字＝人裁字。共 **1,905 格**（殿本 1,014、史記 559、全唐文 332），逐格在 [`benchmark/gold_human.tsv`](benchmark/gold_human.tsv)。

按「参校字与候选的关系」分类（和 N01 深挖同一套）：

| 类 | 含义 |
|---|---|
| A | 参校字与库首位是形近表（手工／字体／人裁表）里一对——**真形近字之争** |
| B | 参校字≠库首位，也不在库前 6 名候选里——库认不出这个字 |
| C | 参校字在库候选里，但不是首位 |
| E | 参校字＝库首位 |
| N | 没有参校字 |

怎么读：

- **整理本可信度因书而异**：史記整理本在这批难例里 559 格只错 2 格；殿本 B 类 24% 不是参校字，而是参校字缺字〓、同词异形（㑹/會、説/說、尙/尚、巳/已）占了 28/31，真错 3 格（雄→間、人→入、白→自）。
- **库首位在这批格里不可信**：殿本全部 1,014 格跟库首位错 32%，史記 22%，全唐文 8%（选择偏差：这些本来就是库和整理本分歧的格）。
- **B 类真字几乎从不在库候选里**（殿本 17%、史記 0）——按候选做文意选择选不对，要么按参校字，要么得另有字形证人。
- **A 类（真形近字）殿本只有一半是参校字**，其余 27% 两边都不是——这正是 N01 该留给文意／人审的格。

判读（**这就是现在要拿来讨论怎么提高的起点**）：

1. **殿本**：任何「跟参校字」的规则都有 13–24% 错，不能做放行通道。残余错误里同词异形占大头，归 V01 的范围（本书该录哪个形）；想放行，得先有「同词异形」的排除（异体边表命中就不跟），再看剩的真错（雄→間 等）能不能用字形证人挡住。
2. **史記**：B 类 38/38、B+C 平常字 56/56 无错，但样本量只够把错率压到 5–12%（上界），**不够上线**（守则：放行子集 0 错且样本够，<100 格抽 30 盲读）。史記 B 类 28＋C 类 7 格现在还在 N01 旧口径里，值得做一次 30 格盲读抽样后开 `ref_lib_coord`／`ref_topk_follow` 之外的「参校字远位」通道。
3. **全唐文**：B 类 2/23 错（璩→據、天→夫），不能无证人放行；已有 `near_knn` 做证人，剩 6 格。

## 四、新书怎么用这套基准

```bash
# 1 抽「形近处境」格（★main 包，每册取 seed_admit/align_ref/glyph_match，抽完删包）
python benchmark/funnel.py <书键…>      # 要 GUJI_DATA_TOKEN；书键对照脚本里 BOOKS，新书加一行
# 2 人裁格做金标：funnel 输出里 prov=human 或 channel=human 的格，真字＝char；
#   分类 A/B/C/E/N 的算法见 score.py 与 gold_human.tsv（照那个表加列）
# 3 给规则打分
python benchmark/score.py benchmark/gold_human.tsv
# 4 候选规则要上线：按准确率守则——金标放行子集 0 错、盲读抽样 0 错（<100 格抽 30，>300 抽 100）
```

新书没有人裁格时：用 `guji-manager iterate gold sample` 从 N01 型格里按类抽 30 格，请 sheldon 用 `review-pages build gold_sample` 页标注，标注结果就是该书的金标；一本书各类至少 30 格才打分。

## 五、局限，用基准时要记得

- **幸存者偏差**：金标是曾经送审的格，库和整理本分歧偏多，不代表全册形近格的准确率。要估全册准确率得另抽放行格盲读。
- **人裁可能顺着参校字**：标注时看到参校字，真错的参校字有可能被放过；金标的「真字＝参校字」比率因此偏乐观，尤其史記。
- **样本量**：0 错也只能说错率 ≤3/n；放行规则上线按守则表定样本量。
- **金标不含放行格的错**（`X03` 机器改了字、放行抽检单独看）。
- **按册留出**：任何训练的东西（`near_knn` 等）要按册留出评估，不要在训练册上评。
- **和 V01 的边界**：参校字与真字同词异形的，归 V01（该录哪个形），不算 N01 放行规则的错，但会让规则的误差看起来很高——所以打分时要同时报「排除同词异形后」的数字。
