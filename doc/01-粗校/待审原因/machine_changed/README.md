## 常见成因

机器推翻了最新人裁（网站现文是人裁的字，本轮机器改了）。

## 怎么处理

1. 人看图定：人裁对就保留，机器对就改。
2. 11-05 起机器改字默认按最新结果进文本，只有推翻人裁的才到这里（cv#1148）。

## 回流与防再犯

频繁推翻人裁说明某类放行有问题，报对应负责组。

## 不要做

人裁永远优先于机器，不要自动覆盖。
