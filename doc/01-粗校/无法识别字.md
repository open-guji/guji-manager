# 无法识别字（`unk`）：图上有字、认不出、Unicode 没有

> 2026-11-13 Sheldon 定（全唐文 007:77:9:15，左「王」右「旦」，查不到任何码位）。网页暂显示「？」，将来换私用区字符或别的方案。
> 格式真源：guji-format spec 02 §4.9、char v0.5（guji-format#31）。

## 一、什么时候用

| 这格图上是… | 用什么 |
|---|---|
| 一个字，人认出来了 | 定字（`confirm shape=X`） |
| 一个字，**认不出，Unicode 里也没有**（只能描述部件） | **无法识别字 `unk`（本文）** |
| 一个字，有近似的已收字，要记原形 | 组字 `zi` |
| 原有字但磨损缺失，看不出 | 阙文（`damaged`，可带推测字） |
| 一个图形、符号，不是字 | 图片格 `fig` |
| 本来就没有字（墨污、切坏） | `not_a_char` |

## 二、book-text 里长什么样

```json
{"a": "77:9:15", "c": "□", "unk": "左王右旦"}
```

- `c` 写 `□`，`unk` 是**部件描述或 IDS**（`左王右旦`、`⿰王旦`）；没写描述的导出补「无法识别」。
- 与 `lacuna`／`guess`／`guess_c`／`zi`／`fig` 互斥；文件 `$schema` 写 char v0.5（`char_schema_for` 自动选）。
- 分行稿 lines.md 里写 `□`（描述不进分行稿，与 Step9 的 lines.md 逐字节一致）。
- 不进检索、不能被 `apply_pending` 填首选字、换包（`swap`）时不被现行字回填。
- **将来换私用区字符**：造字落定后，该格 `c` 改成那个字符、`zi` 记原形、去掉 `unk`，走普通 0.x 小改。

## 三、怎么录（人裁事件）

对 cv 它和图片格是同一条路（不进字形库、不出卡、字位占住出 □），所以**事件不新增 `v`**：

```json
{"kind": "confirm", "target": {"unit": "cell", "key": "vol07:77:9:15"}, "payload": {"v": "figure", "unk": "左王右旦"}}
```

- `payload.unk` 有值＝无法识别字；没有就是图片格（`alt` 为说明）。同格后到的事件为准：先判无法识别、后改判图片格或定字，都以最新一条为准。
- 网站精校票：`choice=unrec`，票上 `unk` 是描述（可空）；`guji cellvotes` 落成上面这条事件（`web_votes.payload_of`）。
- `crop_exclude` 消费者把描述写进排除名单 evidence 的 `unk=…`（理由仍是 `figure`）。

## 四、导出

`feedback.figures.figure_cells(book)` 返回 `{字位: 说明}`，无法识别字的值是 `UnkDesc`（`str` 子类，所以 cv 的导出脚本不用改）；
`formats.guji_page_cv.from_cv_products` 据此在字框上写 `unk`（而不是 `fig`）；`guji_char_cord._char_cell` 写 char 格。

要求 guji-manager ≥ 本改动发版（见 CHANGELOG）。
