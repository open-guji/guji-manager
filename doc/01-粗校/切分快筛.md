# 切分快筛：自动找出切分毛病（SJ，2026-11-10）

> 目的：四层推进（切分 → 字形库缺样本 → 形近字组 → 余下人审）里，第一层要一次清干净，后面少返工。
> 这页记的是：切分毛病分几类、哪类能自动抓、抓得多准、抓到之后归哪一层去修。
> 数据：史記文淵閣本 01–10 册。工具与结果在项目文件夹 `shiji/seg-detect/`（见文末）。

## 一、先分清两类毛病，修法完全不同

| 类 | 例子 | 动不动格号 | 修在哪 | 什么时候必须修完 |
|---|---|---|---|---|
| **结构类** | 漏切一个字、两字并一格、夹注两半并一格、字被拦腰切成两格、格数与整理本对不上 | **动**（格号、格数变） | 切分层：公用算法 → 书级 → 页型 → 列参数 → 格钉子 | 第一层就清零，否则人裁、字形库刻例都要迁 |
| **装饰类** | 格里带了上下邻字的一截残笔、列首/列尾带版框横线或碎点、格边带界行竖线 | **不动**（框只是大了一点点） | 发实例前清格（公用一步：把别格的墨、长直线抹白），**不用重新切** | 字形库收样本之前（脏样本进库后要重收） |

要点：

- 结构类才是「切分返工」的根源，必须在第一层清零。
- 装饰类不该靠挪框修：挪框会动格号，牵连人裁和刻例。应当在出字块时把不属于本格的墨抹掉（夹注左右已经这样做了，叫「发前抹白」），格框原样不动，所以零返工。
- 这一步要排在字形库收样本之前。史記 r35 十册正文里装饰类约 3,300 格（1.45%），其中 98% 已经放行，人审单上看不到，却在当字形样本用。

## 二、检测项与判据（只读产物＋列图缓存，各书通用）

**先做一步**：把列图里的长直线剥掉，即竖向开运算 200px（界行）、横向开运算 0.85 列宽（版框）。不剥的话，史記写本字常常笔画相连，界行又贯穿整列，一串字会连成一块，后面的墨账全算错。

**墨账**：把列图连通块对到格框上，每一块墨归给「框内像素最多」的那一格。

| 代号 | 抓什么 | 判据 | 类 |
|---|---|---|---|
| ORPH | 漏切（一整个字不在任何格里） | 闭运算 9px 后一块墨不在任何格框里（框内墨 ≤20%），墨量 ≥本列格中位墨量 25% 且 ≥150px。排除：版框残带（高 ≤30 且宽 ≥半列或宽 ≥4×高）、界行残段（宽 ≤25 且宽 ≤0.3×高）、稀疏折角（填充率 <0.10）、网点碎点（≥15 块且块中位 <40px） | 结构 |
| JZW | 夹注左右两字并成一个半格 | a/b 半格框宽 ≥列宽 70% | 结构 |
| FOR | 邻字残笔进框 | 框里有别格的墨，按块计：只算块在本框内的部分 ≤本框墨 35% 的「边角」块（避免把笔画相连的邻字算进来）；占本格墨 ≥5% 且 ≥100px。夹注同号另半不算（发前已抹白） | 装饰 |
| Lv | 界行竖线进框 | 剥出的竖线像素在框内 ≥20px，或裁图左右边有与字身隔开的薄竖带 | 装饰（框横向越线） |
| Fpatch | 版框/界栏横线进框 | 裁图上/下边有一条薄横带，与字身之间隔着 ≥2 行空白，覆盖 ≥半宽，厚 ≤max(3, 8%高) | 装饰 |
| Fend／Lh | 列首/列尾格压到版框 | 首/末格框伸到 `column_warp` 的 `border_top/bottom_in_column` ±4px 内，且贴该边 12 行内有覆盖 ≥45% 宽的墨行；或剥出的整宽横线落进框 | 装饰 |

试过、效果差、已去掉的判据：

- 「本字墨落在所有框外」：多是剥线后剩下的碎墨，精度很低。
- 「贴边一条平直横墨」（逐列取首墨点，看标准差）：口、日、西这类方字的上横也平，在 r35 上精度约 20%。
- 「侧边贴边小块」：夹注左右的残笔和字身上下重叠，空白列分不开；分连通块又和字自身的偏旁混在一起。

## 五、怎么用进每一轮

1. 出包后跑三步，十册在云端合计约 5 分钟，前提是列图缓存已经 warm：
   - `seg_detect.py`：逐格 flags；
   - `orphan.py`：漏切块；
   - `aggregate.py`：列清单，结构分排前。
2. 「结构分 >0」的列逐列看图，加上 pending_reason 的 seg_* 列，就是切分层要清的全部。按分层原则修：公用算法 → 书级 → 页型 → 列参数 → 格钉子。
3. 装饰类只计数、不逐格修，发前清格（k4）上线后再跑一遍，计数应当大降。这是字形库收样本前的闸。
4. 侧边残（夹注左右）不进本筛。照 11-09 调查结论，留到字形库层做部件级对位。

## 六、格高、格宽、位置一致性检查（防切错，Sheldon 11-10）

快筛的墨账只看「框里有没有别人的墨」，看不出「框本身该是半格却切成整格」这类：框里干干净净，墨也都是自己的。
所以再加两项几何对照，只读产物：

| 检查 | 怎么比 | r35 十册结果 |
|---|---|---|
| 版式对格号 | `layout_slots` 每列的格位表（大字、小注 a/b、半格、抬头）对 `cell_shrink` 实际出的格号：缺哪些、多哪些 | 17 格「只有右行的小注切成整格」（如 01:21:1:5、02:165:1:21、08:12:8:1）；卷端题署列格号错位 12 处；比版式多出的格 5 处 |
| 格高格宽位置 | 同列正文格高对列中位数、小注 a/b 格高对本列小注中位数、格宽与左右位置对列宽 | 半格切成整格的格，格高约是同列小注的 2 倍、宽却满列，一眼可见；其余离群格看图都是字本身扁长 |

结论（切分线 11-10 逐格看图）：

- 17 格「只有右行的小注切成整格」是真切错，书仓 k3（`jiazhu_step` v1.6）已改切 a 半格，全书模拟改 17 格、无误改。
- 题署列格号错位：字、框都对，只是格号没给版式空位留位置，不影响认字和读序，暂不修。
- 比版式多出的格：切得都对，是整理本那一列与图对不上（列首列尾字归错列、少字），归参校／版式层，不归切分层。

做法：每轮出包后与墨账三步一起跑，结果在 `shiji/seg-detect/r35/版式对格号.tsv`、`格高格宽位置.tsv`。

## 九、一条命令跑完：`tools/seg_check/seg_check.py`（2026-11-11）

上面三步（逐格 flags、漏切块、列清单）加上两项核对，并成一条命令、一份报告。每轮出包后跑一遍，作为「第一层切分是否稳定」的闸。

**准备**（每册约 2 分钟暖缓存，核查本身每册约半分钟）：

```
guji products pack fetch <册> --label <本轮标签> --root <产物根> -w <书仓根>
GUJI_PRODUCTS_DIR=<产物根> GUJI_CACHE_DIR=<缓存根> guji cache warm --book <册> --jobs 4 -w <书仓根>
```

**跑**：

```
python tools/seg_check/seg_check.py --products <产物根> --cache <缓存根> --vols 01,02,… \
    --pins $GUJI_DATA_HOME/main/<工作区id>/feedback/verdicts/char-segmentation/manual-cells/items.jsonl \
    --skip <册:页,册:页-页,…> --out <报告目录>
```

**做了什么**：

| 步 | 查什么 | 归类 |
|---|---|---|
| 几何快筛（`seg_detect.py`） | 逐格 FOR/Fend/Fpatch/Lh/Lv（残墨、框线、界行），JZW（夹注半格并格） | 前者装饰，JZW 结构 |
| 漏切块（`orphan.py`） | 整块墨不在任何格框里 | 结构 |
| 钉子核对 | 中心库 manual-cells 每个钉子列：cell_shrink 出的格号集合必须与钉子一致 | 不一致＝**格号不符**（结构） |
| 版式对格号（给 `--layout`） | 非钉子列：书语料 `layout_slots.jsonl` 的格位（大字 N、小注 Na/Nb；半格是 a^b 不分左右，Na、Nb 都算对上）对实出格号 | 格数不同＝**版式不符**（要看）；格数相同、只是编号不同＝判过，只在报告里计数 |
| 待审原因码（`review.causes`） | A1/A3/A4/A5/A6/A9。所在列有○（`evidence.symbol`）的归「○对位」 | ○对位不归切分；其余归「原因码·看图」 |

**输出**（`--out` 目录）：

- `列清单.tsv`：每列一行，含「类」（结构／装饰／对位）和「处置」：
  - **格号不符**：钉子没生效，或钉子与切分对不上。必须查。
  - **版式不符**：实出格数与版式格位表不同。多半是整理本把列首、列尾的字归到了邻列（框对，归参校），少数是真漏切、多切。要看图。
  - **需钉子**：几何上有结构嫌疑（漏切块、夹注半格并格）的列，要逐列看图。真切错就按分层原则修，最后一层是整列钉子。
  - **原因码·看图**：只有 A 码、列里没有○。r39、r41 看下来多是○被认成别的（A6）或整理本缺字，框都对；03:117:3:6 那种真切错也从这里出来，所以要看。
  - 格数对、编号不同的列不出行，只在报告里计数：题署列（「唐 諸王侍讀率府長史 張守節正義」）大间距不给版式空位留号。A22 11-11 评估：改格号要迁全部题署列人裁、钉子、锚，收益小，不做。
  - **已钉·复核**：钉子列又报结构嫌疑，看一眼钉子框是否要收紧。
  - **对位（○）**：圈号对位问题，交对位／参校，不归切分。
  - **公用清格**：只有装饰类，不逐格修，交发前清格（书级 `code/patch_clean.py` 或 A22 公用层）。
  - **已钉**、**点名跳过**、**卷首页**：只列出，不处理。
- `需看图_*.png`：「格号不符／需钉子／已钉·复核」各列的整列缩略图，红框是字格，标有格号。
- `report.md`：计数和结论。退出码 0 表示无格号不符、无需钉子；3 表示有，要看报告。

**--skip 怎么配**：点名不归本筛的页，比如职名页、年表页（年表页 0 格，本来就不出）、卷端网点页、整页御题印。史記文淵閣本是 `01:39-52,01:54,01:121,01:127,01:138-139,04:124`；p1–3 默认当卷首页单列。

**已知误报与已加的过滤**（漏切块）：

- 版框折角（列首、列尾的┐形框角，墨心贴列边、稀疏）：墨心在列宽外侧 15% 以内、填充率 <0.3 的块不算（r41 05:93:2、06:32:1 等 4 列）。
- 列尾粗版框黑带：宽 ≥0.8 列宽、高 ≤60、填充率 ≥0.25 的块不算（r41 05:50:7、02:171:5、06:52:2）。
- 卷端网点底纹页（史記 01:54「史記集解序」）、整页御题印（04:124）：网点、印文会连成大块，过滤不掉，看图确认后加进 --skip。

## 十一、哪些能钉、哪些要改公用算法

| 问题 | 怎么处理 | 层 |
|---|---|---|
| 单列真切错（漏切、并格、拦腰切） | 整列钉子 manual-cells（`seg_pins_check` 过了再推），格号顺延时人裁靠墨框锚自动迁 | 格钉子（本书） |
| 一格挤两字（职名页「原任」「三等」） | 同上，强行切两格写进钉子 | 格钉子（本书） |

## 十二、标 main 前的切分不回退闸（A22，2026-11-13）

Sheldon 11-13 定：切分检查要嵌进每一轮，但**不要求清零才标 main**，否则后面各层都卡住。改成「不回退闸」：

1. 候选包和现役 main 各跑一次 `guji seg check <册…> --out <目录>`（同页范围、同开关）。
2. `guji seg gate <候选目录> --base <main 目录> --ledger <ai-team domain/CV/A22/切分根因台账.tsv> --book <殿本|史記|全唐文> --new-label rNN --base-label rMM --out seg-gate`。
3. 挡（退出码 3，不标 main）只有两种：**回退**＝候选包里的结构列（钉子未生效／格号不符／版式不符／需钉子）在 main 里不是结构列；**新页级错**＝一页 ≥4 列且过半是结构列，main 那页没这么坏。
   - **格几何没变不算回退**（11-14，全唐文 R020）：seg check 另出 `格几何.tsv`（每列 row_segment 格框＋cell_shrink 字框，整页坐标）。两份都有时，新冒出的结构列若格号集合一样、各边挪动 ≤0.05 格高，记「几何没变」不挡——切分没动，是对位、放行、参校本变了。旧版 seg check 出的目录没有这张表，就不比几何（报告里有提示），两份都要用新版重出。全唐文 s1 对 g1 143 列回退收 53 列，32 列真回退一列不放。
4. 不挡：main 就有的结构列（已知未清）。没挂上根因台账的列在报告里列成「未登记」，请本书切分线登记根因或钉住。
5. 不管挡不挡，都出 `切分未定.tsv`（册、页、列、处置、回退＝是／几何没变／空、根因号）。**下游各层（字形库、形近、人审、文本）照常推进其余页，这张表里的列先跳过或当待审**；切分修好、重跑后自动从表里消失。

漏检的规矩（同日定）：下游任何一层发现切分真错而本轮 seg check 没报，就把这一列登进根因台账、加进本书尺子（`guji seg ruler` 之外的手工尺子同放），下次改检测判据要报这把尺子上的查全。
