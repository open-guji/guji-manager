# 2c 少见字入库、OCR 候选

> 第二步「迭代」的小步。总览见 [第二步 README](../README.md)。

库里缺例、样本少的字头补上本书刻例，让库自己能放；认不出的字由 OCR、5b 笔画证据出候选供人认。

**输入**：待审里 L 类（`lib_missing`、`lib_sparse_*`、`lib_unrecognized` 等）的格；整册跑完后放行格回库的候选。
**输出**：新的字形库快照 `g<N>` 并钉住；少见字四层人审页的结果；回库与库文一致报告。
**命令**：`guji review-pages build char_grid`、`tools/开书/字形快速入库_自动.py scan／ocr／crop／sample／gate／admit`、`guji events route`、`guji glyph-db snapshot／snapshot-upload／pin-verify／selfcheck`、`guji recheck`、`guji triage`、`guji audit alt`、`guji corpus`。

做法以 [迭代流程 第 2 层](../迭代流程.md#第-2-层少见字入库) 与 [字形快速入库](字形快速入库.md)（真源）为准。第一次进库的字必须人裁（11-03 定）；每批新册集中出一次页，不零碎出。OCR 候选：认不出的字先看 5b 两路（分类头、embedding 检索）的候选，见 [5b 笔画证据](../../参考/5b笔画证据.md)；以图代字、私用码见 [无法识别字](无法识别字.md)。
