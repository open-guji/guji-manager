# 2b 切分检查与优化

> 第二步「迭代」的小步。总览见 [第二步 README](../README.md)。

格框对、格号对、配上整理本。切分一动，格号、刻例、人裁锚都要迁，所以每轮最先清。

**输入**：本轮 `guji seg check`／`seg gate` 给出的结构列清单；下游各层报回来的切分错。
**输出**：修好的切分（cv PR、书仓 `code/` 新 `k`、册配置、`manual-cells` 钉子）；根因台账与本书尺子更新；`切分未定.tsv`。
**命令**：`guji seg check／gate／premain／pin／pins-stale／ruler`、`tools/seg_check/seg_check.py`、cv `scripts/seg_pins_check.py`、`guji code release／verify`。

做法以 [迭代流程 第 1 层](../迭代流程.md#第-1-层切分含对位页钉位) 为准：先查根因台账 → 修法由便宜到贵（公用算法 → 书级代码 → 本书配置 → 单页单列钉子）→ 漏检即进尺子。看图判切分由会话做，不交用户。
