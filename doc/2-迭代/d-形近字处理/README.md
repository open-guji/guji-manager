# 2d 形近字处理

> 第二步「迭代」的小步。总览见 [第二步 README](../README.md)。

同组字（末未木、入人八、嗚鳴、剌刺…）和异体、码位，能靠字形和规则定的由机器定。本小步不用 AI，凡要读文意才能定的（日曰、己已巳、千干…）一律留给[第三步](../../3-AI文意判字标点专名/)。

**输入**：待审里 Z（字组）、N（形近护栏）、V（异体）类的格；人裁改字、金标盲读错例里反复出现的字对。
**输出**：每组的判法（刻形模板／CNN、码位归一、书级形近表与规则，或明确「靠文意、交第三步」）；金标；码位口径。
**命令**：`guji groups table／status`、`guji promote mine`、`guji pair-attr`、`guji model`、`guji iterate gold／audit`、`guji suggest`、`guji review-pages build gold_sample／pair_whitelist／codepoint`。

做法以 [迭代流程 第 3 层](../迭代流程.md#第-3-层形近字处理非-ai) 为准。新放行规则上线：金标放行子集 0 错，独立盲读抽样也 0 错（<100 格抽 30、>300 抽 100、>1000 抽 200）。错放先归因：缺样本回 2c、切分对位回 2b、组内判别留本小步、整理本错另记。模型与归属表见 [5a 相似度模型](../../参考/5a相似度模型.md)、[5a 形近字对分类器](../../参考/5a形近字对分类器.md)、[形近字对归属表](../../参考/形近字对归属表.md)。
