# 命令速查

令牌写环境变量名，不写值；详见 [环境与令牌](环境与令牌.md)。

## 工作区与中心库
| 命令 | 用途 |
|---|---|
| `guji db init -w <工作区> [--dry-run]` | 新工作区进中心库前初始化 |
| `guji db push -w <工作区> [--dry-run]` | 推册 yaml 等（写用 `GUJI_DATA_TOKEN=$GUJI_DATA_TOKEN_PROD`、`GUJI_ACTOR=<你>`） |
| `guji db pull -w <工作区>` | 拉到数据目录 `$GUJI_DATA_HOME/main/<id>/` |
| `guji db status -w <工作区>` | behind／unpushed |
| `guji db sync` | 写人裁事件并推库 |

## 原图
| 命令 | 用途 |
|---|---|
| `guji source spreads <源件> --vol 01 --out splits.json --sheet 核对图.png` | 对开拆页 |
| `guji source commons <书id> 01 --djvu <源件> --commons-json commons.json --splits auto --dry-run` | 登记 Commons 来源的原图（PDF 也收） |
| `guji source ia`／`guji source register` | IA 来源／已有目录的老书 |
| `guji source pull <册> -w <工作区>` | 按页表取图到 raw_dir |

## 管线
| 命令 | 用途 |
|---|---|
| `guji pipeline <管线> <册> -w <工作区> [--pages dev_set\|all] [--from 步] [--to 步] [--no-pack] [--override JSON]` | 跑管线 |
| `guji status --pages all` | 各步过期／缺失情况 |
| `guji close-check --tier rough` | 粗校出口检查 |
| `guji products pack list／fetch／push／promote` | 产物包 |
| `guji exp run` | A/B（只差 seed_admit 参数时） |

## 任务库
`export GUJI_JOBS_WHO=<你>`；`guji_jobs ls`、`submit [--override '{...}']`、`show <号>`（跑完不通知，自己查）。spec 里新书带 `ws_repo: <owner>/<repo>`，老书带 `ws_glob`。规范见 [重跑需求与执行规范](../02-粗校/重跑需求与执行规范.md)。

## manager 自带
`guji-manager check`（pipeline 契约兼容检查）；`guji opinions …`（人审意见）；`guji_manager.online_lists`（标 main 后重出线上单）。
