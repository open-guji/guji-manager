# 边界与数据流

## 一、pipeline 与 manager 的分界

**凡会影响最终识别产物字节的在 pipeline**（仓 [open-guji-cv](https://github.com/open-guji/open-guji-cv)：图像处理、切分、识别、定字、放行规则、Step9 汇总与 char.json 导出）；**其余在 manager**（本仓：工作区、取图、打包推中心库、R2、任务库、人审意见、线上单重出等一切与外界的交互）。

- 所以改 manager **不需要给 pipeline 发版**，也不会让任何一册的产物过期。
- pipeline 保留 `open_guji_cv` 名字与 tag 线（模块全名进 `code_hash`，改名＝全册过期）；manager 用 `m-vX.Y.Z` tag，**不钉到册、不进产物指纹**。
- 调用方式：manager 通过子进程跑 `guji-cv --json`；接口契约见 cv 仓 `doc/契约.md`，兼容矩阵见 [COMPAT.md](../../COMPAT.md)。过渡期 manager 可 import cv 内部，cv 的 `guji.commands` 插件机制把 manager 的子命令并进 `guji`。设计原文：cv 仓 `doc/design/拆分-pipeline与manager.md`。

## 二、对象与关系

| 对象 | 是什么 | 住哪 |
|---|---|---|
| Work／Book | 作品／版本，一书一个 Book ID | book-index 仓（A11 目录） |
| 原图（页表、页图、源件） | 以 Wikimedia Commons 文件为根，R2 是派生存档 | R2 `pack/source/pages/<书id>/<册>/r001.json` 等 |
| 工作区 | 一部书一个仓（`guji-workspace` 组织），仓根即工作区；`workspace.yaml` 的 `id` 用书 ID | 工作区仓 + 中心库 `workspaces` 表 |
| 册 | 整理的最小单位，一个 `books/<册>.yaml`；基础配置 `config/book_defaults.yaml` 对工作区内全册生效 | 中心库 `books`、files 表 |
| 产物包（pack） | 一次跑批的全部产物，带 cv 版本、语料、字形库的标签；可标 main | R2；`guji products pack list/fetch` |
| 语料／参校本 | 逐列整理本，做对位和放行的证据 | 中心库 `corpus/` |
| 字形库 | 分书存、可跨书借用 | 中心库 / glyph_store |
| 事件（人裁、意见） | 追加型事件，按 `source_rev` 门控 | 中心库 feedback events |
| 文本成品 | 按册导出的 char／cord／norm 与标点、实体层，文本线版本 0.x → 1.0 | book-text 仓（dev 提交，每日合并 main） |
| 线上待审单 | 网站精校页的数据 | 中心库 → kaiyuanguji-web（proofing-sync） |

细节：[中心库](../参考/中心库.md)、[册配置](../参考/册配置.md)、[产物包与版本钉](../参考/产物包与版本钉.md)。

## 三、数据流（整理一册书）

```
book-index ──▶ 原图登记(R2 页表) ──▶ 工作区仓/册 yaml ──▶ 中心库
                                                      │ guji db pull/push
                          任务库 guji_jobs ──▶ 执行机 ──▶ pipeline(guji-cv) ──▶ 产物包(R2)
                                                      │ 标 main
                       online_lists 重出线上单 ◀──────┘
                                │                       └─▶ 导出 ──▶ book-text(dev→main) ──▶ 网站
                                ▼
                  网站精校页投票 ──▶ opinions 落事件 ──▶ 受影响页重跑 ──▶ 升版（回到 book-text）
```

阶段对应：[01 开新书](../01-开新书/) 走到「册进中心库、试跑」；[02 粗校](../02-粗校/) 跑整册并首次入 book-text；[03 精校](../03-精校/) 走票与重跑循环；[04 点校](../04-点校/) 往 book-text 加标点／实体层；[05 反馈迭代](../05-反馈迭代/) 处理 1.0 之后的外部反馈。第 2–4 步的推送到 book-text 在各自文档中说明，发布不单列一步。
