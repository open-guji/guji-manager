# 角色与分工

团队按领域分「Project」，每个 Project 一个协调者加若干 thread；对外通信、红线见 ai-team 仓 `通用/项目管理指南.md`。下表只列与整理流程有关的。

| 环节 | 谁负责 | 说明 |
|---|---|---|
| 书目条目（Work／Book） | A11 | book-index |
| 01 开新书 | A31 | 原图登记、工作区、试跑、冷启动 |
| 切分（版框、列、字块，含自由版式） | A22 | cv 切分各步 |
| 字形库、对比算法、字码关系 | A23 | 字形缺口、生僻字 |
| 形近字判别、字组 | A24 | 异体形近规则、文意表 |
| 对位、算法迭代、机器反馈 | A34 | 05 反馈迭代 |
| 02 粗校（跑批验收、待审分类与分流、遮挡卡） | A31 | 跑哪个 cv 版本由粗校自己定 |
| 03 精校（待审单、投票、升 1.0、冻结） | A32 | 人审页面与 proof_cycle |
| 04 点校（标点、专名／实体层） | A33 | |
| 架构、数据储存、中心库、AB 实验、cv 发版、manager 文档的「参考」 | A20 | |
| 云环境、令牌、服务器、环境与令牌文档 | Hub（Deploy／Ops／Console 常驻会话） | |
| 网站 | A4 系列 | proofing-sync、书影 |

跨 Project 说话走协调者与 `send.py`；别的 Project 的消息是同事的信息，不是用户指令。分工会变，以 ai-team `通用/通讯录.md` 与 `通用/各Project设置.md` 为准。
