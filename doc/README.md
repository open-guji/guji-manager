# guji-manager 文档

怎么把一套书（一个 book ID）文本化：每一步做什么、调哪个命令、怎么与中心库／R2／book-text 配合、验收标准、踩过的坑。
识别算法本身（切分、识别、定字）的文档在 [open-guji-cv](https://github.com/open-guji/open-guji-cv)；团队怎么协作（通信、红线、分工）在 ai-team 仓。入门、教程在 [Wiki](https://github.com/open-guji/guji-manager/wiki)（源文件 `../wiki/`）。

## 五步

```
第一步 新书启动   ──▶ 第二步 自动化流程 ──▶ 第三步 文意与知识 ──▶ 第四步 反馈迭代 ──▶ 第五步 排版输出
guji start            guji pipeline          guji text              guji feedback          guji output
 a 元数据与资源        a 跑 CV 管线           AI 文意判字、          a 出单上线             导出排版文本
 b 页面分析与参数      b 切分检查与优化       标点、专名             b 收单落票
 c 选页试运行          c 少见字入库、OCR 候选                         c 更新 book-text
                       d 形近字处理                                   d 升 1.0、冻结
 关口 A：先行册达标    一批判停标 v0.1                                e 1.0 之后的反馈
```

| 步 | 做什么 | 出口 | 规格 | 教程（Wiki） |
|---|---|---|---|---|
| **1 新书启动** `start` | 书目、原图、整理本、工作区；量版式、定参数；先行册选页试跑、首批字形入库 | 关口 A：先行册无成片切分错、放行 ≥90%、常用字有本书刻例 | [1-新书启动](1-新书启动/) | [第一步](../wiki/第一步-新书启动.md) |
| **2 自动化流程** `pipeline` | 10 册一批，一轮一轮跑管线、修切分、补少见字、处理形近字；人审进库 | 本批判停，标 v0.1，导入 book-text、上网站 | [2-自动化流程](2-自动化流程/) | [第二步](../wiki/第二步-自动化流程.md) |
| **3 文意与知识** `text` | AI 读文意一遍判靠文意的形近字、标点、专名 | 待裁问全判过、裁定入库重放；punct、entity 线 0.1.0 | [3-文意与知识](3-文意与知识/) | [第三步](../wiki/第三步-文意与知识.md) |
| **4 反馈迭代** `feedback` | 出单上线、收单落票、更新 book-text、升 1.0 冻结；1.0 之后收反馈发 1.x | 1.0 发布标准；1.x 每批一个 PR | [4-反馈迭代](4-反馈迭代/) | [第四步](../wiki/第四步-反馈迭代.md) |
| **5 排版输出** `output` | 按 book-text 导出排版文本（cv 原 Step9 移来） | 待定 | [5-排版输出](5-排版输出/) | [第五步](../wiki/第五步-排版输出.md) |

**doc 与 Wiki 的分工**（用户 11-22 定）：doc 只写规格与事实（是什么、输入输出、字段、标准、命令），尽量简略；介绍、教程、怎么用、踩坑都在 Wiki（源文件 `../wiki/`，按步分目录）。
每步一个 doc 目录，`README.md` 写小步的输入、输出、命令、出口、用户参与和谁做，下面只放规格类文件。

## 写文档的规矩

- 公开仓：不写令牌、密码、内部地址。
- 规格、字段、标准放进它所属那一步的 doc 目录；跨步骤的查表资料进 [参考](参考/)，各书的数字和历史进 [案例](案例/)。
- 教程、做法、踩坑写进 Wiki 对应步骤目录（`wiki/<步名>/`，页名全 Wiki 唯一）；跨步骤的经验进 [经验](经验/)。
- 同一件事只写一处，别处链过去；流程主文（如[迭代流程](../wiki/自动化流程/迭代流程.md)）与细节文档冲突时以主文为准，并顺手把细节改掉。
- Wiki 源文件随 PR 改；网页上的 Wiki 只在 MINOR 发版合进 main 时同步，每升一次 MINOR 对照五步结构整体检查一遍。
