# 第一步　新书启动

从一个 book ID 开始，把先行册（2–3 册）准备到能整册跑、能分批迭代的状态。做完进入[第二步 迭代](../2-迭代/)。

```
1a 元数据与资源 ──▶ 1b 页面分析与参数 ──▶ 1c 选页试运行 ══ 关口 A：先行册达标 ══▶ 第二步
  书目、原图、整理本、    版式档案、页型、套书、    dev_set 试跑看图、
  工作区仓、进中心库      册配置、书级开关、体检单   借库首跑、首批字形入库
```

| 小步 | 做什么 | 主文 | 主要命令 |
|---|---|---|---|
| [1a 元数据与资源](a-元数据与资源.md) | book-index 条目；原图登记进 R2（拆对开、页表）；找整理本做成语料；建工作区仓与书仓 `code/`；册进中心库 | [a-元数据与资源](a-元数据与资源.md) | `guji source`、`guji corpus init`、`guji db init／push`、`guji code release` |
| [1b 页面分析与参数](b-页面分析与参数/) | 量版式、页型普查、选套书（`seg_set`）、写册配置与书级开关、墨层二值、借库口径、出开书体检单定目标人审率 | [b-页面分析与参数](b-页面分析与参数/) | `guji pagekinds`、`guji binarize`、`guji suggest`、`guji pending-stats` |
| [1c 选页试运行](c-选页试运行/) | 取图；`dev_set`／samples 10–30 页试跑看叠图；整理本钉页位；借库首跑；先行册首批字形快审入库 | [c-选页试运行](c-选页试运行/) | `guji source pull`、`guji pipeline … --pages dev_set`、`guji product overlay`、`guji seg check`、`guji triage`、`guji review-pages` |

完整清单（含会话分工、「人不用催」机制、全唐文实测时间线）见 [开书全流程（详细版）](开书全流程-详细版.md)；其中「阶段五铺开」以后的内容已归第二步。

## 入口条件

- 定好要整理哪部书、哪个版本（用户定；多个扫描本时选善本，理由写进[案例](../案例/)页）。
- 有 book-index 写权限、Commons／R2 的写令牌（见 [环境与令牌](../00-总览/环境与令牌.md)）。
- 工作区仓由用户先在 `guji-workspace` 组织下建好，并给该组织装 Claude 的 GitHub App，否则 `add_repo` 只有只读。

## 先行册怎么挑

2–3 册，不是 1 册（一册积累的字形太少，史記册 01 只收到约 2,000 个）：
1. 一册**正文最典型**的（全唐文册 04）；
2. 一册**特殊页型最多**的（卷首、序、目录、表、职名、考證多的册）；
3. 可选一册另一种体裁（史記：本纪、表、书、世家、列传各不同）。

先行册把切分、参照、字形库磨好，第二步铺开时其余册直接沿用册配置模板、套书、书级代码 `k`、格位表脚本和字形库 `g`。

## 出口（关口 A，会话自判，不问人）

| 小步 | 标志 | 怎么核 |
|---|---|---|
| 1a | book-index 有 Work／Book，Book 只挂一个最新原图资源 | `check_schema.py`、`check_v2.py` 过，PR 已合 |
| 1a | 原图在 R2，页表页数对，对开拆页核对图逐张看过 | `guji source commons … --dry-run` 页数；红标落在折痕上 |
| 1a | 有逐列整理本，或明确记下「没有」 | 语料进中心库 `corpus/`；没有则冷启动那套用不了 |
| 1a | 册在中心库 | `guji db status`：behind 0、unpushed [] |
| 1b | 版式档案写好；每个新页型有一张叠图拼图给用户看过（只告知，不等） | 工作区 README、`guji pagekinds` 对账无漏 |
| 1b | 开书体检单出了，用户定了目标人审率 | 后台「迭代轮次」有目标线 |
| 1c | 先行册无整页／整列成片切分错 | `guji seg check` 无整页错；叠图看过 |
| 1c | 放行 ≥90%、正文 ≥95%；常用字有 15–20 个本书刻例 | `guji pending-stats`；字形库深度分布 |

## 用户参与点

| 什么时候 | 做什么 | 规模 |
|---|---|---|
| 1a 开头 | 给 book ID 和已知资源，点开书授权 | 5 分钟，一次 |
| 1a（若需要） | 建工作区仓、给组织装 GitHub App；有歧义时选版本、选参校本 | 一张决定卡 |
| 1b | 看新页型的叠图拼图（不阻塞）；定目标人审率 | 每型 1 分钟；定目标约 10 分钟 |
| 1c | 先行册首批字形快审（第一次进库的字必须人裁） | 每册约 1–2 小时 |

写中心库、合 PR、标 main、存产物包，凡在开书授权范围内的不再逐次问。

## 谁做

各书线自己做（史記 SJ、全唐文 QTW、殿本 ZM）；切分不适配的版式交 A22，字形库 A23，形近字 A24；共用框架、跨书的事归 A31。
