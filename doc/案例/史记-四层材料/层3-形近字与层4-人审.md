# 层3 形近字 与 层4 人审：经验与脚本（史记，2026-11-12）

## ① 形近组（cv groups/registry 共55组，字头清单见 shiji/形近组字头清单-1111.md）
- 定组：先看实际错放（待审、人裁改字、gold 盲读错例）里反复出现的字对，再入组；同组字靠组内判别，不能凭单字相似度自动入库（字形线入库脚本要排除全部组字头）。部首/字形差别大的错（駱/路、清/瀆）不是形近，是○邻对位或切分错，归切分线（A9）。
- 判法分三类：①整格靠字形可判（先看图与字形库样本）；②靠上下文判（日曰、己已巳、令今、大太等），用「文意两路」；③字形文意都拿不准的留人审。日曰、己已巳不参考整理本（整理本可能就是错的），按文意定。
- 文意两路双轮规则：两个干净会话只读±5字上下文，候选顺序正/反各一路；一格必须至少两轮（两次独立会话）、两路全一致且都 high 才写人裁，source 标「文意两路 rN 双轮」，否则留待审。r41：整格日曰/己已巳16格，首轮一致7格，双轮通过3格。
- 金标盲读：开任何新放行（如面→而、大→太、宫）前，先按组抽30格金标，盲读错数为0才开；有错先修判法不放行。
- 错放归因：每个错放先判是字形库缺样本、切分/对位、组内判别、还是整理本错，分别回给对应层，不混着调参数；不为个别格改算法参数。

## ② 人审页经验
- 一律用 guji-manager 模板库（review-pages build gold_sample 等），不手写 HTML；用户意见改模板，不改已发页。
- 页上显示库里的首选字，不显示「待选一串」；格图从原页图裁格（crop_cells），带前后文；不默认全对，要人明确点；机器已预判的格不放进人审页。
- 一次攒大批，不拆小批（Sheldon 要求）：未定格进「人审总清单」累积，重跑后一次性给；人裁记账写清为什么需要人裁、裁多少格（台账模板 rounds/r11）。
- 人裁写事件前：db pull、push --dry-run，确认 glyph_exported=false、无删除；本地有未推文件时 pull 会拒，先把未推文件移出再 pull、移回后推，切勿 --force 或 --no-rebuild。

## ④ 开新书第三、四层清单与已知坑
1. 一二层（切分、字形缺样本）清零后才进第三层。
2. 清单：跑 pending-stats 看哪些组占待审大头→定组→金标盲读→文意两路→人裁入库→重跑核对放行与逐格一致。
3. 层4：待审总清单、攒一批、用模板出页、写台账。
坑：整理本在日曰/己已巳上不可信；○邻格错放不是形近；pull/push 顺序与 glyph_exported；磁盘紧时只拉必要册并用后删缓存；年表页整页跳过；事件锚（墨框）要用 enrich_events 补，产品目录 GUJI_PRODUCTS_DIR 指到书 id 层。
