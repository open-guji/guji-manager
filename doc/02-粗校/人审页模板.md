# 人审页模板

> 状态：现行 v1（2026-11-05，A31；sheldon 11-05 定「人审页 artifact 模板都存进仓库，持续优化」）。代码在 `guji_manager/review_pages/`，命令 `guji-manager review-pages`。

## 一、降人工的规矩（靠 OCR 与参校本比对）

1. **三方一致不上页**：参校本字＝库首位＝独立识读（文本层或 OCR）且字形分过门槛 → 走算法放行（要过[降人审迭代框架](降人审迭代框架.md)第五节验收），不给人看。
2. **只给人看分歧**，按分歧类型分组排列。
3. **一字一卡**：同字头合一卡，人看 3–5 个样例即放全书同字，其余跟随并按抽检补核。
4. **预选**：参校本字 / 文本层字 / 大模型读法预选，附依据和置信；高置信组可「全部确认」。
5. **独立 OCR 第三证人**：有文本层用文本层；没有的书评估行 OCR（keben_free 的 line_ocr，paddleocr），先在金标上量一致率。
6. **点过即录入、撤出页**；只写改动格到 db，不整页重发布。审页图按 cell_shrink 字框裁。己已巳日曰这类要文意的不进快审页。

## 三、版本与优化

- 每个模板带版本号；每次使用记「页型、版本、格数、用时、改判数、预选错数」进台账。
- 按台账优化：哪类预选错得多就改哪类的预选来源或排序。
- 发布成 Artifact 给人用；回收走 db。

## 四、用法（v1）

`--book` 用书 ID（如史記 988g3f0wsu、全唐文 995ejelvk0、殿本 96mid1ogzk），不用书名；后台存档 id 只认 ASCII，页面里 saveDoc 也会把非 ASCII 编码成 `-xx` 再存。

```bash
guji-manager review-pages list                                   # 页型与版本
guji-manager review-pages preselect --cells cells.jsonl --out o/ # 预选：三方一致 → auto.jsonl（不上页），其余 → page.jsonl + stats.json
guji-manager review-pages build char_card --items o/page.jsonl --book 988g3f0wsu --out card.html   # 同时写 card.cards.json
# 用 Artifact 发布 card.html（要 db 能力）；人点完后 ArtifactData list 存成目录 res/
guji-manager review-pages expand --cards card.cards.json --results res/ --out decisions.jsonl # ok/bad/follow/audit
guji-manager review-pages ledger add --type char_card --from-results res/ --book 988g3f0wsu
guji-manager review-pages ledger summary                         # 按（页型，版本）出 秒/格、改判率、优化提示
# 码位定夺（按组看图定夺，doc/01-开新书/按组看图定夺.md）：找组、渲图仍用 tools/开书/按组看图/find_groups.py、render.py
guji-manager review-pages cp-items --groups groups.json --cache $WS/cache --out cp.jsonl
guji-manager review-pages build codepoint --items cp.jsonl --book 995ejelvk0 --out cp.html   # Artifact 发布，db 能力
guji-manager review-pages cp-apply --results res/ --who Sheldon > 片段.yaml            # codepoints 片段＋follow_ref＋分开/未定
# 字块质量（列端框线评测集等）：直接吃 dataset 分片；已有标签的字块不上页（--all-crops 全上，复核用）
guji-manager review-pages build glyph_quality --items $DS/char-segmentation/frame-end-crop/items.jsonl \
    --root $DS/char-segmentation/frame-end-crop --book frame-end-crop --out gq.html     # Artifact 发布，db 能力
guji-manager review-pages gq-apply --results res/ --out labels.jsonl                  # 标签 jsonl（res/ 可放导出 JSON）（可直接当 --exclude，按 sha 撤块）
guji-manager review-pages gq-apply --results res/ --shard items.jsonl --out items.new.jsonl   # 回写信封 label＋history
```

- **字块质量**（`glyph_quality`）：items 也可自给 `{id, book?, char?, end?, ctx?, ref?, crops:[{key, sha, img}]}`（`ctx` 原图上下文、`ref` 同字参照，可省）。同格两块 sha 相同只上一块（标签两版共用）。存档用通用件 `_store.js`：每块一项，项 id＝`格号|sha`（文档 `i_<safeId>`，集合 `review_glyph`），字段 `{page_type, tpl_version, book, cell, vol, sha, key, keys, label: clean|frame|cut|unsure, how: click|page_ok, t}`；「本页其余都干净」把没点的块记 clean（`how=page_ok`），没点也没翻过去的块不算确认。回写按（格号, sha）对，sha 对不上（字块变了）不写，要重出页再看。放大框与并排是 `_common.js` 的共用组件 `glyphBox`/`glyphPair`（`.gbox`，`--gbox` 改边长），形近字对比等页型也用它。

- **码位定夺的四种结论**（结果 `pick`）：`unify:X` 统一作组里的 X、`other:X` 合并到组外字 X → 进 `config/codepoints.yaml`；`split_follow` 分开·互认（两种刻法各记，整理本作另一形也照刻形放，不送审）→ `book_defaults.yaml` 的 `params.seed_admit.follow_ref` 双向；`split_distinct` 分开·不同字（照刻形、不互认，全唐文 嚴/巖、㣥/羣、青/靑）→ 不进任何配置，码位表里已有的要撤出。旧页只有一个「分开」，两种意思混在一起（全唐文 11-01 的「分开」都按互认落，11-04 的 嚴/巖 是不同字），所以拆成两个。配置要推中心库数据目录 `config/`，见按组看图定夺第三节第 5 步。

- **预选输入**（`cells.jsonl` 每行）：`{id, ref参校字, lib库首位, lib_score, text文本层字, ocr, llm大模型读法, llm_conf, img}`。三方一致且 `lib_score≥0.95` → auto；其余按分歧类型（参校≠库、参校缺、库没有、独立识读不同、无独立识读、字形分不足）分组，预选＝多数票（平票参校本优先），置信 high/mid/low。auto 的放行仍要过[降人审迭代框架](降人审迭代框架.md)第五节验收，不是这里决定。
- **一字一卡**：同预选字合一卡，抽 5 格给人看（先放置信最低的 2 格），其余跟随；全唐文用 `--per-card 3`（Sheldon 11-04：每类 3 个够，剩下的下一轮自动认）。样例有「不对」→ 整卡判 audit，跟随格不放、退回逐格；卡头可改字（整卡改）。跟随格放行后按第五节抽检补核。
- **逐格点选（char_card 1.1.0 起，QTW 审页并入）**：点格子循环 1 切分有问题（seg）→ 2 改字（格下出「这格是什么字」输入框，**不预填**参校字）→ 3 看不清（unclear）→ 4 对 → 再点取消。建议字放格子顶上、大字。每点一下只把这一格写进 db（文档 `c_<格号>`，`{id, card, v: seg|unclear|other|pick:<字>, t}`），不整页重发布；「本页其余都对」另存页文档，没点的样例记对。打开页面时从 db 恢复逐格结果。
- **点过即录入、撤出页**：`expand` 把逐格文档与页文档合起来（逐格比页文档新）；只有逐格文档的卡只出点过的格，跟随格不出。录入后把已录入格号存成文件，下一波 `build --exclude landed.json …` 撤掉这些格再发布。
- **审页图**：`guji-manager review-pages crop --cells ids.txt --shrink-dir <工作区>/cache/{vol}/cell_shrink --pages-dir <图目录> --page-name '{page}.png' --out crops/`，按 cell_shrink `bbox_page`（右上角原点）裁；不要按 row_segment 的 quad 裁，会带进栏线，人会误判成切分问题。
- **模板版本**：改模板就改 `registry.py` 里该页型的 `version`；结果文档自带 `page_type`、`tpl_version`、`secs`（有效操作秒数，间隔超 30 秒按 30 秒计）。
- **台账**：`ledger summary` 按（页型，版本）看每格秒数、改判率，每个分歧类型改判率 >15%（≥20 格）提示改预选来源，每格 >6 秒提示合卡或换页型。台账文件默认 `$GUJI_REVIEW_LEDGER` 或当前目录 `review_ledger.jsonl`；建议放项目共享目录并定期提交。
- 结果回流：一字一卡/快审页的 ok 格走原 `ingest_char_review.py`（confirm 事件、glyphdb_admit）；其余页型的结果文档由各自消费者读（gold_sample 的字段与 A24 `labels2` 相同）。

## 七、每种页的必备功能（验收清单）

新模板、改模板都要过这张表；`tests/review_pages` 按表加用例。

1. **点一下就存后台**（db 能力），不靠「下一页」才存；存档文档带 `page_type`、`tpl_version`、`book`，id 只用 ASCII（`safeId`）。
2. **重开能接着做**：本机暂存＋从后台读回（换设备、清缓存不丢）；升小版本时读回旧版本的本机暂存。
3. **已录入的撤出页**（`build --exclude`），只给人看还没定的。
4. **信息给全**：字块图按 cell_shrink 字框裁；前后文（【】标整理本字）；预选及依据；多路候选每个注来源；判语/分类。
5. **候选都不对也能定**：手填字、切分错、看不清、库里无此字（备注写 IDS）。
6. **进度与用时**：进度条、已审页数；只算有操作的时间。
7. **导出**：一键导出 JSON（db 不通时兜底）。
8. **手机能用**：窄屏不横滑，按钮够大；键盘可操作。
10. **预选口径**：预选字高亮显示并注明依据，手填框不预填；人没动的格只有点「本页其余都对」才记为确认（兼顾 SJ 要预选、QTW 要不预填）。
9. **同一批改版发到原地址**：改版重 build 后发布到原 Artifact 链接，本机暂存才接得上。

**逐项存档（所有页型同一套，`_store.js`）**：点一下写一份文档 `i_<id>`，字段＝该项结果＋`{id, page, how, t}`。`how=click` 是人点过；`how=page_ok` 是人翻页点了「本页其余都对」按预选认下；**没有文档＝未确认**，下游不得当全对。用时另存 `s_…` 文档（`kind=secs`）。读取统一走 `results.flatten`，命令：

- `review-pages unconfirmed --items items.jsonl --results DIR`：列出还没确认的项。
- `cp-apply --items items.jsonl`：除了出配置，还列未确认的组。
- `ledger add` 按页归并逐项文档，用时取 secs 文档，未确认项不入账。
- `char pull`（char_grid）两种文档都认；`expand`（char_card）每格带 `kind`（pending_reason）。
- `review-pages closeout-sum --results DIR`：收口单各去向格数合计。

**预选口径（各页统一）**：预选字／选项带「预选」标并注明依据；手填框不预填；没点的项只有点「本页其余都对」才算确认（how=page_ok）。

**pair_whitelist 1.2 新增**：`review-pages pair-items --cells cells.jsonl --out items.jsonl [-n 30]` 按字组各抽 30 格（格号哈希，稳定可复现）；cells 每行 `{id, group, img, left, right, ref_char?}`，前后文按正文/小注读序展平。页上逐格点「同字／不同字／看不清」，每组页尾显示同字率，再定组结论；`pair-apply --results DIR [--min-rate 1.0 --min-judged 30]` 汇每组同字率并列出可入白名单的组（越过整理本白名单按书按组定，不继承别的书）。

**codepoint 2.2 新增**：字体缺字（私用码、僻字）的候选在组里给 `glyphs:{字: 图}`（或 `rows[字].img`），页上用字形图代替文字；`cp-items` 读 groups.json 的 `glyphs`。

**gold_sample 1.1 新增**：按 kind（放 pending_reason）筛选；`--mode check` 核对模式（显示机器答案和来源，只点「对／错（填字）／看不清」）；items 可带 `strip`（邻格字块图）、`strip_at`（目标格红框），下面配前后各 12 字；`ref_char` 在上下文里标【】。切分错／看不清／库里无此字的 `pick` 记作 `__seg__`／`__unclear__`／`__none__`（`verdict` 字段同值，无此字请在备注写 IDS）。
