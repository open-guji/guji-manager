# 终审判读与开关建议（一天做完一本书的两条自动化）

> 状态：现行（2026-11-05，A31）。设计依据：ai-team `domain/CV/质检/迭代降人审框架/新书降人审迭代框架-2026-11-05.md` 第六、十一、十四节。

## 一、诊断信号 → A 档开关建议（`guji-manager suggest`）

首跑出数后，不靠人读表配开关：

```bash
guji-manager pending-stats --out /tmp/ps                       # cells.tsv 现在带 ref、top、tok 三列
guji-manager suggest --cells /tmp/ps/cells.tsv --out /tmp/ps   # → suggestions.md／suggestions.json
```

建议分三种：

| 类型 | 意思 | 例 |
|---|---|---|
| `patch` | 有确定键值，点头就能写 | `params.seed_admit.symbol_ref_blank: "○"`（从 `seed_admit` 重跑） |
| `sample` | 开关明确，但开之前要按字对／页抽样看图 | `follow_ref_variants` 或 `follow_ref_seen`（每对抽 10 格 0 错）、`seal_detect.stain_pages`（只列真印页） |
| `action` | 不是 yaml 能解的 | 跑终审判读、先做 seg_causes 归因、第一次进库字走一字一卡页 |

**建议不会自己写。** 点头后只写 `patch`：

```bash
guji-manager suggest --suggestions /tmp/ps/suggestions.json --apply <册.yaml> --accept 1
```

写法是文本追加进 `params:`（不重排整份 yaml），写完核对合并结果与预期一致；键已存在则拒绝覆盖。册 yaml 要改的是**中心库数据目录**那份，写完照 [书级开关与跑批分支](书级开关与跑批分支.md) 推库，推前核 `params_hash`，再从提示的起点步重跑（D 轮 `seed_admit`）。

## 二、大模型只读文意终审（`guji-manager final-review`）

殿本 r4 的 build／finalize／write_rulings 抽成跨书命令，换书不改代码。流程：

```bash
# 1 一键：选格 + 取窗口候选 + 按类分批
guji-manager final-review run --pkg <产物包根> --cells /tmp/ps/cells.tsv --out <工作目录> --book "《某书》刻本" [--vols 20-50] [--classes Z,N] [--vol-fmt "vol{n}"]
# 2 按 <工作目录>/sessions.md 开判读会话（干净新会话，不调 API；A/B 两路不互看）
# 3 核齐 → 门槛+金标 → 写裁定
guji-manager final-review status   --out <工作目录>
guji-manager final-review finalize --out <工作目录> --pkg <产物包根> --whitelist ly,dt --gold gold.tsv
guji-manager final-review write    --out <工作目录> --ruling-dir <feedback/rulings> --batch llm-ctx-YYYYMMDD-m1
```

要点：

- **按类分批**（`pending_reason` → 类）：Z 字组、N 形近护栏、L 库样本少且与参校本不一致、P 参校本不一致、D 遮挡但参校本有字。每类一份提示词（`prompts/<类>.txt`），P/D 把参校本当证人问「放进去通不通」；每会话约 350 格，A 路候选原序、B 路倒序。a/b 半格不判（归 S），R 类、V 类、L01/L03 不在此列。
- **放行门槛**（`finalize`）：两路同字且都 high、字在候选里；**越过参校本只许 `--whitelist` 里的 Z 组**（按书按组抽 30 格金标定，不继承别的书）；N/L/P/D 只收与参校本同字；字形分 ≥0.95 或 ≥2 个独立来源；L 类给 `--glyph-db` 时选中字库样本须 >2。
- **金标挡板**：`write` 要求 `finalize` 时给过 `--gold` 且放行子集 0 错，否则拒写（确实不需要加 `--no-gold`）。放行 >100 格的类别另按 [降人审迭代框架](降人审迭代框架.md) 第五节抽独立盲读。
- **全部写**：没放行的也写 ctx_ruling（记弃权），免反复问；裁定键为格号＋上下文哈希，重切后仍命中。推库前按 push-safety：备份、pull 核账本非空、设 `GUJI_ACTOR`。
- 开会话本身不在命令里：`sessions.md` 是会话清单与指令模板，由协调者或人逐个开（每个会话 1 个文件进、1 个文件出）。`status` 报哪些没回齐，重开那几个即可。
