# 书级开关与跑批分支

> 来源：史记文渊阁线（2026-11-02）。适用于任何「这本书的版式／整理本有特殊性，要在册 yaml 里加书级配置」的书。

## 一、书级开关的写法原则

1. **缺省关，且证明等价**：新键缺省时产物必须与改前逐字节相同。先在不开的册上重跑一批页对比，通过后登记 `code_equiv`，再合 dev。
2. **用有语义的参数，少散开关**（用户偏好）：同一类意图收成一个参数。例：`reference_trust: none|high|very_high` 取代 `ref_lib_coord`、`ref_lib_coord_blind`、`group_flow_shape_ref_ok` 三个散开关（cv #866）。
3. **多道闸，任一不过退回人审**：例 `roster_seal_despeckle` 三道闸（每格像字／格数＝整理本字数／列端非印边残点）。放行的新格要逐格看图抽验。
4. **改册 yaml 推中心库**：先 `guji db sync` 拉最新，只叠自己那几行，不动别的线程的改动；推完告知「跑批」负责线程重跑。（用户 11-02 授权：推中心库直接做，PR 自审自合。）
5. 配置写进册 yaml 即随册生效；**旧 cv 读到不认识的键会静默忽略**，所以跑批分支必须带上对应 PR（见第三节）。

## 三、跑批分支（任务库不能直接用 cv dev）

**坑 1：dev 拒跑。** dev 上 fdadc15 改了四个字组 `ids_bank.json`（qi、sang、shang、suan），与本书语料 v1 的钉对不上，glyph_match 起跑前 `require_pin_clean` 报 CorpusDrift。临时绕过 `GUJI_CORPUS_DRIFT=warn` 会让结果与基线不可比，不用。根治是出新语料版本、改钉（要另行决定）。

**坑 2：旧分支丢开关。** 用 ba2b739 系旧分支（claude/shiji-run）会静默忽略新键，例如 `table_pages` 缺了，09、10 册年表页切回来，多带回约 1,400 格待审。

**做法：** 以 ba2b739 为底，把 dev 上之后合入的书级开关逐个 cherry-pick。现行分支 `sj-fg-on-run`（6dd79f1）= ba2b739 + #849 + #854 + #857 + #864 + #865。**还没移植的**：`reference_trust`（#866）、`layout_slots_grow`（#870）、`coord_dp`（#856）——新交跑批前先确认要带上哪些。基线包 `…-fg-base-ba2b739`。

**每次交跑批前自检：** ① 分支带了册 yaml 里全部键对应的 PR；② 先在 3–4 页上试跑看新键生效；③ 结果与上一轮基线对比（`code_equiv` 缺省等价的页应逐字节一致）。
