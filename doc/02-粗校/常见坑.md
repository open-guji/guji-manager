# 02 粗校：常见坑

- **语料漂移拦跑**：册钉的语料版本与引擎仓文件漂移时，glyph_match 被 CorpusDrift 拦。临时用环境变量 `GUJI_CORPUS_DRIFT=warn` 绕过，根治是出新语料版本并改钉（北行日錄遇到过）。
- **旧 cv 读瘦身册会静默丢基础配置**：跑 vol51–99 一律 cv ≥ 0.5.23。往基础配置加键前先查 vol01–50 是否会被改变（它对工作区内所有册生效）。
- **`--params` 显式传默认值**旧版会被册 yaml 静默改回，现按 `model_fields_set` 判；实验用 `--override`，不改文件不推库。
- **云端 R2 取原图／任务 prep 极慢**（1–1.5 小时），`source pull` 偶发读超时，重跑会接着缓存继续。
- **非 vol 编号的册名**（如 bxgb）：`republish.py` 的 chapter_of 返回 000，要显式 `--chapter`、`--text-id` 并自己 `--export-dir` 导出；progress_report 会误写 vol='000' 的行。
- **`guji db pull --no-rebuild` 之后 glyph.db 为空文件**会让 `db sync` 报 no such table: sources，删掉重 pull，再 `guji glyph-db rebuild`。
- **事件读口按 source_rev 门控**：给册钉 `source_rev` 前，要把指向该册页的旧事件补上 `target.anchor.source_rev`，否则旧人裁被丢。
- **分析必须用出单版的产物包**，否则格号对不上。
- 印章遮挡：异体形近规则优先于印章；遮挡须「印章框内 + 格内噪点 ≥ 4」才算（cv#722、#724）。
- 任务库提交可能被自动审批拦，需用户明确说「交」；重跑完不通知，要自己 `guji_jobs show`。
