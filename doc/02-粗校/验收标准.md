# 02 粗校：验收标准

## 入库（出 0.1.0）按 R1–R6

| # | 条件 | 判 |
|---|---|---|
| R1 | 全页全步骤在固定 cv 版本下不过期 | `guji status --pages all` stale／缺失／失败／阻塞 = 0 |
| R2 | 三道闸失败的页／列都有去向 | 异常表每行有结论 |
| R3 | 人审率报数（目标 < 1%，不卡出口，要写原因） | 分册人审率表；超标册写分类原因 |
| R4 | 异常清单都有结论 | 无「没人看过」 |
| R5 | 导出过格式检查 | `guji close-check --tier rough` 机器项全过 |
| R6 | 整页／整列不丢字不错位 | 页级跳过的页逐张看图；col_gate／colgap 报警逐个看 |

## 每轮重落的验收（对比 A→B），顺序固定

1. 放行字变 = 0，或逐格看图确认全是改对；
2. 人裁没带过来 = 0；
3. 人审率下降且不靠松阈值；
4. 切没了／新切出的列有交代；
5. 新出现的送审类别有解释。

放行错必须为 0 是目标；字形判法上线门槛是按册留出 0 错。重跑完默认标 main 推库，只有程序级严重 bug 才拦，少数错放是预期内的，不要求零回退。

## 本步骤完成标准
每册都有统一格式的粗校报告＋异常表；R3 超标的册写出分类原因；待审分类报告每轮更新；没有「只在某会话里知道」的结论（全部落进文档或 Jira）。
