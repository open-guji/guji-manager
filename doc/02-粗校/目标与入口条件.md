# 02 粗校：目标与入口条件

## 目标
用固定的 cv 版本把一册（或一整套）整册跑完，检查通过后入库 book-text 文本线 0.1.0；再分析剩下的待审格，把各类交给对应小组优化，循环到人审率压到目标以下。

人审率目标 < 1%（不卡出口，但要写原因）；质量红线：自动放行错放 = 0 是目标，少数错放在成批重跑里是预期内的，只有程序级严重 bug 才拦。

## 入口条件
- 这一册已按 [01 开新书](../01-开新书/) 进了中心库，原图在 R2。
- 册 yaml 钉好 `cv_version`、`corpus`、`glyph_pin`。**没跑过的册一律钉最新 cv 版本**；老册换哪个版本由粗校负责人自己定并自己改钉（cv 的守卫、特性开关只要测试过就全册都开）。
- 跑 vol51–99 一类瘦身册须 cv ≥ 0.5.23（旧版会静默丢基础配置），见 [册配置](../参考/册配置.md)。
- 执行环境见 [环境与令牌](../00-总览/环境与令牌.md)。

## 谁做
粗校负责人（A31）定册、定版本、验收、分析与分流；跑批走任务库自己提交（见 [步骤](步骤.md)）；切分、字形、形近字的修复分别归 CV 各组（A22 切分、A23 字形库、A24 形近字）。
