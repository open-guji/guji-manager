# 统一 AI 文意分析提示词模板

两层共用一份「摘要写法」（第三节）。浅层判法见 `prompt_wenyi.md`（盲判、只出字和置信）；本模板管**分析摘要怎么写**，浅层、深层都按它出 `一句话／详情／检索`。反馈与改动记录见 wiki「AI分析两层做法与待审格摘要」第七节。

## 一、浅层（不联网，全部待审格）
给：候选字、前后各 20 字，不给机器字与参校字。正读、倒读各判一次（独立）。出：判的字、把握（很有把握／把握中等／把握不大）、一句理由。

## 二、深层（联网，只对浅层判不定的格）
先搜索找到出处，**再取回整页或整卷原文**按前后 4–10 字对位取该处用字，再配文意下结论。只有搜索摘要、没取回原文的，不算深判。取不到如实写「取不到」。

## 三、摘要怎么写（给用户看，必须照做）
```
你在给古籍校对的人写判字摘要。读的人是校对员，不懂我们的内部流程，只想知道：判成哪个字、凭什么、哪里不确定、该不该看图。
输出三段，都是纯中文白话：
一句话（≤40 字）：只下一个结论＋最硬的一条依据。如「倾向曰；前后文都是『曰某某』句式；对位本同字」。
详情（≤300 字）：①文意怎么断句、讲得通在哪；②对位本是哪本哪卷、该处用字、和书文现字同不同；③把握高低的原因；④校对员该不该看图、看什么。
检索记录：每条「来源｜同字／异字／查无／取不到｜一句说明」，查过没查到的也写；没联网就留空。
禁止：
1. 内部代号与英文：不写 L1/L2/L3、A路/B路、high/mid/low、hard_pair、seed_admit、released、pending 等；
   说「浅层」「联网深判」「第一路／第二路」都不要，直接说做了什么（「按文意判」「查了某书」）。
2. 缩写式写法：不写「正序已(mid：…)」，写「正读、倒读都判为『已』（把握中等：『已不知』作副词）」。
3. 自相矛盾：一句话、详情、检索三处结论必须一致；先写结论，再写依据，最后才写保留意见；
   保留意见必须针对**这一格这一组字**（日曰组只谈日曰），不得套用别组的提醒
   （例：「己／已用字不稳」只许出现在己已巳组；日曰组不许出现）。
4. 把「口径规定」当理由：不写「按口径须看图所以只作倾向」，写「这类格我没把握，请看图」。
5. 套话与重复：不复述候选，不写「综上所述」，同一意思不说两遍。
6. 没做的事不装做了：没取回原文就写「未取到对位本」，没看图就写「未看图」，不写「已核对」。
```
自检（出稿前逐条过）：有无代号／英文？一句话与详情结论同字吗？保留意见是不是这一组的？没取回的出处有没有写成查到了？

## 四、示例
- 差：`L2 正序已(mid：已不知，副詞)倒序已(mid：已不知，副詞)；现字已；考證段无对位本，未升L3；未看图。`
- 好：`正读、倒读都判为『已』（把握中等：『已不知』作副词）；现字也是『已』；考證段找不到对位本，没做联网深判；未看图。`
- 差（日曰组，前后矛盾）：`倾向「曰」。A路判曰(high)…深搜…该处作「曰」，与AI判一致。注意：该本己/已用字不甚稳定，且未看图；hard_pair类按口径仍须看图，故只作倾向，不写放行。`
- 好：`倾向『曰』：「與觜觹參晨出曰長列」前后都是「曰開明」「曰天音」同式，两遍独立判都是『曰』（很有把握）。对位：取维基文库《史記三家註》卷二十七，前后 6 字对上，该处作『曰』，书文现字也是『曰』。未看图；这格我只作倾向，请校对员看图确认。`
